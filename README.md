# スタジオまあね

AIを活用して価値ある商品を作り、継続的な収益を生み出す小規模デジタルビジネス。

## 基本フロー
1. product の `input.md` に課題を定義
2. 7AIがそれぞれの役割で調査・分析
3. 各AIが `output/{ai}/` に成果を保存
4. 7AIの中からproductに最適な統合AIを自動選定
5. 統合AIが全AIの成果を比較・検証
6. `final/product.md` に最終成果物を作成

人間は原則として課題設定と最終確認を担当し、AI間の役割分担や統合担当の選定は自動化する。
