## 物語の基本構造

- 綴町は「届かなかったもの」「終わらなかったもの」が集積する町。
- 「結」という存在が、3年前の事件によって「向こう側」に留まっている。
- 6人の登場人物が、それぞれ自分の「未完了」と向き合い、最終的に結との関係を変えていく。

## 6人

役割は以下の6つを基本とする。

1. リーダー
2. 藤原＝観察
3. 調停
4. 現実
5. 感性
6. トリックスター

フルネーム・年齢・性格などの詳細は「6人の詳細設定」を参照。

## 6人の呪いの文法（骨子）※Round 8確定

Round 8にて、6人を「傷」そのものではなく「自分を守るためのルール（自己規定）」として設計する文法が確定した。各人物は以下の要素で構成される。

- **未完了**：過去に終わらせられなかったもの
- **呪い**：未完了から形成された「自分はこうしなければならない」という自己規定
- **引力**：呪いを手放せない理由。手放すことへの恐れ
- **代償**：役割そのものではなく、役割にしがみつく理由・執着を手放すこと
- **代償後**：抽象的な成長描写ではなく、以前なら無意識に選んでいた具体的行動を選ばなくなる変化として描く

各人物の「呪い（自己規定）」の骨子は以下の通り。

| 役割 | 呪い（自己規定） |
|---|---|
| ①リーダー | 自分がすべて決め、責任を負わなければ誰かが傷つく |
| ②藤原＝観察 | 正しく観察していれば、間違えず・傷つかずに済む |
| ③調停 | 自分が折れれば、その場は丸く収まる |
| ④現実 | 現実と正しさだけを見ていれば、失望や損失を防げる |
| ⑤感性 | 感じたことを誰かに理解させなければ、自分の存在は成立しない |
| ⑥トリックスター | 本気にならなければ、傷つくことも失うこともない |

※この表はRound 8で複数AIの議論から収斂した骨子。各人物の性格・未完了エピソード・手紙の内容はRound 9で確定（下記「6人の詳細設定」「手紙」参照）。

## 6人の詳細設定 ※Round 9確定

### ①リーダー：槙野拓海（まきの たくみ）・27歳

- 職業／出自：実家の工務店の現場監督見習い。綴町生まれ育ち。祭りの実行委員長役を断れない立場。
- 性格：明るく決断力がある。周囲からは「頼れるが近寄りがたい」と見られている。
- 未完了：中学2年生の頃、目の前でいじめを見ながら自分で決めることを避けて多数決に委ねた結果、親しい友人が転校した。
- 引力：決め続けることで、かつて「決めなかった」失敗を償えると信じている。
- 行動パターン：会議や飲み会を「まあ、こうしよう」で必ず自分が締める。
- 身体的クセ：決断する直前、顎に触れて全員の顔を順番に見る。→代償後：消える。

### ②藤原＝観察：藤原幹（ふじわら かん）・25歳

- 職業／出自：町立図書館司書。綴町出身。3年前の夏、結の異変を感じ取った。
- 性格：無口、観察好き、記録魔。周囲からは「物静かで優しいが何を考えているか分からない」と見られている。
- 未完了：高校時代、妹の不登校の予兆を日記に事細かに記録していたが、「大丈夫か」の一言が言えないまま、関係は3年間そのままになっている。
- 引力：観察していれば、責任を問われずに済む。
- 行動パターン：誰かが何か言うと、まず手帳にメモを取ってから答える。
- 身体的クセ：書く前にペンをカチッと鳴らし、相手から視線を外す。→代償後：残るが意味が変わる（防御の記録から、対話のためのメモへ）。
- 3年間観察の証拠：測量野帳12冊。1日1ページ、天気・結の帰宅時間・図書館の来館者数のみ記録し、感情は書かない。端に鉛筆で「声をかけるべきだったか？」と書いて消した跡が全冊にある。

### ③調停：小柳倫子（こやなぎ みちこ）・24歳

- 職業／出自：町役場福祉係、実家は駄菓子屋。綴町出身。
- 性格：笑って場を収める、断れない。周囲からは「優しい、空気を読む人」と見られている。
- 未完了：両親の離婚協議の夜、母を守るために父に何度も謝り、自分が折れたことで場は収まったと思っていたが、本音は一度も聞いてもらえないまま、家族の対話は終わらなかった。
- 引力：折れれば拒絶されずに済む。
- 行動パターン：揉め事が起きると「私がやります」と自分の予定を消す。
- 身体的クセ：折れる直前、笑いながら首の後ろをさする。→代償後：消える。

### ④現実：七瀬理香（ななせ りか）・26歳

- 職業／出自：測量士、現在は空き家管理NPO。3年前に町外から移住してきたよそ者。
- 性格：論理的で正直、現実的な解決策を出す。周囲からは「クールで正しいが冷たい」と見られている。
- 未完了：大学のゼミで、共同研究データの不備に気づき正義感から指摘したところ、教授には表面上感謝されたが研究室の空気は一変し、それまで親しかった仲間から徐々に距離を置かれるようになった。「間違っていたのは向こうなのに、なぜ自分が孤立するのか」という感覚に、今も納得がいっていない。
- 引力：正しさだけは、人間関係のように裏切らないと信じている。
- 行動パターン：夢を語る相手に「予算は？期限は？」と現実を突きつける。
- 身体的クセ：正しさを口にする直前、腕を組んで唇を噛む。→代償後：残るが意味が変わる（詰問の間から、相手の話を聞くための間へ）。

### ⑤感性：雨宮創（あまみや はじめ）・22歳

- 職業／出自：コンビニ夜勤、祖父のアトリエで絵を描く。綴町出身。町を出たいが、自己表現の場を町に求めてもいる。
- 性格：感情豊か、繊細、言葉選びが独特。周囲からは「不思議、扱いにくい」と見られている。
- 未完了：子供の頃、古びたトンネルの前で「風が泣いている」と感じたことを誰も信じてくれなかった。唯一分かってくれると思っていた祖父にだけは打ち明けようと機会をうかがっていたが、忙しさに紛れて言い出せないまま「言うタイミング」を逃し続け、今もその一言を伝えられていない。
- 引力：理解されれば、自分の感覚は正しかったことになる。
- 行動パターン：作品や考えを見せては「どう思う？どう思う？」と繰り返し聞く。
- 身体的クセ：理解してほしい時、相手の袖や指先を軽くつかむ。→代償後：消える。

### ⑥トリックスター：坂本るい（さかもと るい）・21歳

- 職業／出自：休学中の大学生、配信・祭りの手伝い。綴町出身。
- 性格：明るく軽い、場をひっくり返すアイデア屋。周囲からは「つかみどころがなく、ふざけているように見える」と見られている。
- 未完了：中学の文化祭、本気で作った映像作品を提出する予定だった当日、親の再婚で急な転校が決まり上映に立ち会えなかった。友人たちには「どうせ中途半端だったんでしょ」と笑われ、本気だったことを証明できないまま終わった。
- 引力：本気にならなければ、笑われても平気でいられる。
- 行動パターン：大事な話をギャグにする、「行けたら行くわ」で約束をぼかす。
- 身体的クセ：ポケットに手を入れ、口角だけ上げて笑う。→代償後：残るが意味が変わる（はぐらかし笑いから、本気を隠しきれない照れ笑いへ）。
- 手紙への向き合い方（Round 10確定）：①〜⑤の人物より逃避的でよい。すぐには開けない、誰かに押しつけようとする、一度捨てかけるなど、「本気になりたくない」という呪いが手紙という「大事な話」への態度にも表れる形にする。

**年齢について**：6人の年齢はRound 9提案段階より引き下げている。これはAIの議論から出たものではなく、統合判断を確認したDragon自身の指示（「主人公たちはもっと若い方がいい」）を反映したもの。

## 手紙 ※Round 9確定

- 6人全員が受け取る手紙は1通のみ。差出人は結（3年前に書き、藤原が保管していたもの）。
- 文面（全員共通）：「あの日のこと、私は忘れていないよ。だからあなたは、あなたのままでいてください。」
- 各人物は、この同一の文面を自分の呪いのレンズを通して異なる意味に誤読する。

### 手紙の受け渡し ※Round 10確定

- 藤原は3年間、この手紙を手元で保管していた。①話の冒頭、藤原はこれ以上持っていられなくなり、衝動的に拓海へ渡す。継続的な配達役としての行動ではなく、一度限りの衝動的な行動として描く（NOT_CANON.md参照）。
- ②藤原自身の話数では、手紙を新たに「発見する」のではなく、3年間しまっていた場所が今は空になっていることを描く。
- ③〜⑥の4人については、明確な受け渡し経路を描く必要はない。それぞれの生活動線上に自然に現れる形（発見場所は各話で個別に設計）でよく、誰が置いたかを厳密に説明しない。

## 結の人物設計・3年前の事件 ※Round 11確定

- 結の年齢：20歳。3年前の事件当時は17歳、高校2年生の夏（6人＜21〜27歳＞よりわずかに年下）。「守られるべき庇護対象」と「対等な当事者」の中間に位置づける。
- 結は、他人の「未完了」や執着を善意から肩代わりしてしまった。
- その結果、境界を不安定化させ、自らが3年間「向こう側」に留まり、崩壊を食い止め続けていた。
- 結の呪いは「自分が救わなければならない」を基本とする。
- 結の最終的な代償の身体的表現＝差し伸べられた手を取らず、自分の手を自分の胸元へ戻し、自分自身を抱きしめる。（Round 9確定）

### 事件の具体的な描写（結の視点）

- 時期：3年前の夏の夜。天候は雨〜夕立直後。
- 結は、廃止された古い郵便ポストに一通だけ残っていた、届け先の住所がすでに存在しない（更地になっている）、赤の他人宛ての手紙を見つける。6人との事前の接点はない。
- 結は手紙を届けようとするが届け先はない。「じゃあ、どこに行けば届くの？」と考えた末、向こう側へ自ら踏み込む。
- 向こう側で大量の「届かなかったもの」（手紙・言えなかった言葉・終わらなかった約束）の集積を見る。
- 「これを全部置いて帰ったら、また誰にも届かない」と考え、自分の意思でその場に残ることを選ぶ。連れていかれたのではなく、善意と17歳特有の万能感・未熟さによる自己選択。
- 事件直後の結自身の認識：「私は良いことをした」という満足感。現在（3年後）の認識：自分の選択の限界に気づき始めている（8話で表面化）。エゴ・自己欺瞞を独立した根幹テーマとして明示はしないが、この「満足感→限界への気づき」という設計自体がその萌芽を無理なく内包している。
- 藤原の位置づけ（3年前の夏、結の異変を感じ取った）と時期的に接続する。

### 手紙が向こう側からこちら側へ渡った経緯 ※Round 12確定

- その夜、藤原は結の異変（図書委員としての夏期返却対応の欠落、野帳上の帰宅記録の途切れ）に気づき、後を追って旧郵便局跡地へ向かう。
- 境界の封印が最も揺らいだ瞬間、結が向こう側から古い郵便ポスト（こちら側で長年ガムテープと錆によって封じられ、7話で拓海が手を伸ばしかける「未使用ポスト」と同一のもの）の投函口へ、書いたばかりの手紙を押し込む。
- こちら側では固着していたガムテープが「バサッ」と音を立てて剥がれ、紙の端が2cmほど暗闇に覗く。すぐそばにいた藤原がそれを引き抜く。
- 藤原が手紙を抜き取ったことで物理的な接点が塞がり、以降この経路は二度と機能しない。ポストが両側に同時に存在するという重なりは、取り壊し直前・お盆の夜・向こう側からの逆方向の投函という条件が重なったこの一夜・一点のみで発生した一度限りの現象とし、他の場面・他の人物には反復・応用しない。
- この経緯は、数字伏線（未投函◯通、31→24）および7話の「触らないで」の未使用ポストの2点と接続しており、新設定を増やさずに既存の2要素を回収する。
- 執筆時の注意：手紙の経路の描写は音と質感（錆・テープ・湿気）にとどめ、謎解き・仕掛けとして演出しない（8話以降の「心理的共鳴のみ・実務因果なし」というトーンとの整合を優先する）。

## 藤原の位置づけ ※Round 8確定

- 藤原は「観測者の末裔」ではなく、血筋・組織による監視者でもない（不採用。NOT_CANON.md参照）。
- 藤原は個人として、3年間にわたり綴町・結を観察し続けてきた。

## 物語構造上の確定方針

- 6人と結の物語では「未完了」「呪い」「代償」を重要な構造として扱う。
- 6人の変化は、単純な一直線のドミノではなく「共鳴」を基本とする。
- 共鳴とは、前の人物の変化が次の人物を「救う」ことではなく、次の人物自身の自己認識を揺さぶり、「自分も同じ問題を抱えているのではないか」と気づかせることを指す。（Round 8確定）
- 共鳴は心理的な揺さぶり・違和感に限定する。前の人物の行動が次の人物の実務・生活上のトラブルとして直接波及する構成（実務因果の連鎖）は採用しない。（Round 10確定。NOT_CANON.md参照）
- 6人の基本的な連鎖方向は、①→②→③→④→⑤→⑥とする。
- 3年前の事件は、6人の未完了が合体して発生したものとはしない。
- 結は6人を一方的に救う存在ではなく、自身も呪いを手放す必要がある。
- 6人の代償プロセスは、全員が同じように美しく・自発的に成功する構成にしない。⑤は12話時点で表面的な代償（誤った代償）にとどまり、真の代償を後半へ遅延させる。⑥は共鳴連鎖から構造的に離脱し、他者からの指摘ではなく自らの気づきで発火する。（Round 8で大枠確定、対象人物・方法はRound 9で確定）

## 代償の考え方

- 代償は単なる犠牲ではない。
- 「役割そのもの」を差し出すのではなく、その役割にしがみついていた理由・執着を手放すことを基本とする。
- 代償後は「成長した」などの抽象表現だけでなく、以前なら無意識に選んでいた具体的な行動を選ばなくなる変化として描く。
- 身体的クセは、呪いが発動している瞬間に出る無意識の防御動作として設計する。（Round 8確定）
- 身体的クセの消滅／転用の人物ごとの選択は「6人の詳細設定」を参照（Round 9確定）。

## 演出ガイドライン ※Round 16確定

演出上の反復要素（環境描写・身体的クセ・小道具・直感など）は、設定・心理・因果関係を説明するために機械的に使用せず、既出の要素に新しい意味や変化を与えるために使用する（共通原則）。

- **環境アンカー**：同一時空間を異なる人物の視点から描く場合、原則として両視点に共通する環境音・環境描写を1つ以上配置し、同一の場を共有していることを自然に示す。アンカー自体を伏線・謎解きとして強調しない。視点・場面の性質上不自然になる場合は無理に配置しない。
- **身体的クセの質的変化**：人物の身体的クセを再登場させる場合、同一の動作を単純に反復するだけでなく、音・強さ・速度・震え等の質的変化によって、その時点の心理状態を示す。身体的クセを心理状態の説明記号として機械的に使用しない。代償後は、同じ動作が残る場合でも、その意味が以前と異なることを優先する。
- **「直感」の言語化**：人物が相手の変化を直感的に察知する場面では、察知した内容を完全な説明・分析として言語化しない。「何かが違う」「以前とは違う」と感じる程度の認識を基本とし、変化の原因や意味の確定は後続の行動・会話に委ねる（数値的な上限は設けない）。ただし、人物の性格・役割上、ある程度の具体的認識が自然な場合はこの限りではない。
- **野帳等、重要アイテム描写の反復**：藤原の野帳に関する物理的ディテール（消し跡、鉛筆の跡等）は、同一の意味を持つ説明として繰り返さない。再登場させる場合は、既出情報の再説明ではなく、その時点で新たに生じた意味・心理的変化（例：過去への執着から対話への転換）を伴わせる。野帳そのものの存在・使用を制限するものではない。

## 15話の大枠

- 1〜6話：6人それぞれを提示（①→⑥の順）。
- 7〜8話：結との接続、3年前の事件への手がかり。
- 9〜13話：6人がそれぞれの呪いを手放していく。
- 14〜15話：6人と結の相互授受、結自身の呪いにも決着。

### 1〜6話の構成方針 ※Round 10確定

- 6話とも「朝に日常→夕方に手紙→夜に誤読」という同一の時間構造にはしない。人物ごとに時間軸の形自体を変える（例：単日で完結する話数、2日にまたがる話数、半日の移動を軸にする話数、夜間のみで完結する話数など）。
- 手紙への向き合い方も人物ごとに差をつける。読むタイミングの早い／遅いだけでなく、誰かに押しつけようとする・捨てようとするなど、より踏み込んだ行動の差も積極的に検討する（⑥るいについては上記「6人の詳細設定」参照）。
- 1〜6話の詳細な場面単位のプロットはDiscussion #21で確定（Round10.mdへのマージ後は同ファイルを参照）。

### 7〜8話の構成方針 ※Round 11確定

**7話**
- 冒頭：藤原、図書館閉館作業。3年間保管していた手紙の置き場所が空になっているのを見る（既存演出の延長）。
- 中盤：6人がそれぞれ別々の生活動線上の理由で、旧郵便局倉庫／旧集配センター跡地に個別に集まる（結に呼ばれてではない）。
- 終盤：拓海が、投函口が塞がれているはずの未使用ポストに手を伸ばしかける。「触らないで」という声（姿は見えない）が全員に聞こえる。
- 主視点：群像・非対称。藤原で開幕し、中盤以降は拓海の行動を軸に他の5人を点描する。

**8話**
- 主視点：結。3年前（手紙を書く場面）と現在（向こう側から6人を見る場面）を交錯させる。
- 読者は、6人が持つ手紙と同一の文面を結が書いている場面を見て、「6人はこの手紙を誤読しているのでは」と気づき始める。
- 結の手紙の真意そのものは明かさない。
- ラスト：結が向こう側から6人を見て、6人の様子に動揺する短い台詞で終わる。確定文言：「……どうして、みんなここに」（Round 12確定）。この時点の結の内的独白は予兆レベルにとどめ、6人それぞれの呪いを理論的に理解している描写にはしない。
- 9〜13話へ温存する情報：本人たちがいつ・どう誤読に気づくか／結自身が「自分の言葉が他者を縛っている」と気づく瞬間。

9〜13話の内訳（Round 9確定・大枠）：

- 9話：①の代償。
- 10話：②と③の代償・共鳴（同時進行）。
- 11話：④の代償。
- 12話：⑤の表面的な代償（誤った代償。真の代償は14話以降へ遅延）。
- 13話：⑥が共鳴連鎖から構造的に離脱し、独力で発火する。

### 9話の場面単位プロット ※Round 12確定（骨子）

- 代償の定義：「決めることをやめる」のではなく「他人の選択の結果まで自分の責任として回収することをやめる」（既存の「代償の考え方」原則の適用）。
- 構成：8話ラストの直後、同じ夜のうちに短い場面を置いてから（クールダウン。尺は圧縮でよい）、翌日の日中パートへ移る。8話→9話の接続を完全に切らないため、同夜の場面はゼロにしない。
- 記憶想起の装置：倫子の身体的クセ（折れる直前、笑いながら首の後ろをさする）を見た瞬間、拓海の中で中学2年の記憶（多数決に委ねた際、転校していく友人が最後に見せた笑顔）と重なる。この「友人の笑顔」の具体像はRound 12で新規に設計されたもので、他の既存記述には登場しない。
- クライマックス：拓海の身体的クセ（顎に触れて全員の顔を順番に見る）が、決断すべき瞬間に出ないことで代償を示す（既存の「代償後」演出原則の適用）。
- 藤原への波及：心理的な違和感にとどめ、実務因果は作らない（既存原則の適用。10話へ接続）。

### 10話の場面単位プロット ※Round 13確定（骨子）

- 構成：D案の変形「同一場面内共存＋時間差代償」。9話翌日の夕方（17時台〜20時台）、藤原の勤務先である図書館で藤原と倫子が短時間（約30分）共存し、その後は別々の場所（藤原＝図書館周辺、倫子＝実家の駄菓子屋）でそれぞれ単独に代償する。共存場面は共鳴の発生に限定し、2人の代償の瞬間そのものには時間差を置く（同時にきれいに代償しない）。
- 藤原の代償：「正しく観察していれば責任を問われずに済む」という引力を手放し、自分の不作為を記録の対象に含める。身体的クセ（ペンをカチッと鳴らし視線を外す）は消えず残るが、意味が「自分を関与させないための防御」から「見たものを引き受けるための儀式」へ反転する。カチッの後、視線を外さないまま書く、という形で変化を示す。
- 藤原が書き足す一文：「声を、かけなかった。」野帳の端に3年間書いては消してきた「声をかけるべきだったか？」（疑問形）への応答として、初めて疑問形ではなく断定形・過去形で書く。他者に読まれることを前提とした告白や手紙ではなく、私的な野帳の記録という形式を保つ（NOT_CANON.md参照）。
- 倫子の代償：「折れれば拒絶されずに済む」という引力を手放し、拒絶される可能性を引き受けたうえで一度だけ自分の希望を口にする。
- 倫子の身体的クセの扱い：9話（拓海の記憶想起トリガーとしての他者視点）とは切り離し、10話では倫子自身が動作（笑いながら首の後ろをさする）に入りかけた瞬間、初めて自覚して止める。代償後は消える方向を維持する。
- 共鳴の接点：図書館で倫子が「折れる」動作に入りかけるのを藤原が観察し、自分の「観察して関わらない」姿と重なって揺らぐ。直後、藤原がいつもと違い視線を外さずに野帳へ書く姿を倫子が目撃し、「この人は今、何かを引き受けた」と直感する。相手を直接救う描写・実務因果は作らない。
- 尺配分：藤原55%：倫子45%。藤原の代償は「書く」という静的動作、倫子の代償は「電話口で断る」という対人的動作で密度を確保し、体感の重さを揃える。
- 10話ラスト：藤原はペンのクセを残したまま視線を外さず書く人物になり、倫子は場を丸く収める笑いを手放す。2人の間に直接の言葉のやりとりはない。11話（理香）へは、倫子が「折れなかった」ことが役場内で伝わり、理香の「正しさ」への違和感の萌芽として引き継がれる。

### 10話 試験執筆で確定した演出ルール ※Round 15確定

- 検証結果：Round 15の試験執筆（MuseSpark・Gemini提出）により、10話Scene A「図書館・共鳴の発生①」・Scene B「図書館・共鳴の発生②」・Scene C「藤原の代償」・Scene D「倫子の代償」は、プロットレベルの矛盾なく小説として成立することを確認した。発見された課題はすべて描写レベルであり、Round 13で確定した場面設計の再設計は発生していない。
- 演出レベルの追加候補（環境アンカー、身体的クセの質的変化の描写、Scene Bの直感の言語化粒度、Scene Cの野帳描写の使い回しリスク）はいずれも未確定のため本セクションには含めない。Round 16へ持ち越し（詳細はSTATUS.md参照）。

### 1話・9話 試験執筆で確定した演出ルール ※Round 14確定

- 検証結果：Round 14の試験執筆（MuseSpark・Gemini提出）により、1話Scene A「手紙の受け渡し」・Scene B「呪い発動」、9話Scene C「記憶想起」・Scene D「クライマックス」は、プロットレベルの矛盾なく小説として成立することを確認した。発見された課題はすべて描写レベルであり、プロットの再設計は発生していない。
- Scene B/D対称性の担保：拓海が顎に触れる瞬間、周囲の人物の視線が一瞬だけ期待をもって拓海に向く、という反応を挿入する。「顎に触れる＝裁定の合図」という読者の記憶アンカーを強化し、9話クライマックスでの不発（代償の提示）を検知可能にするための演出ルール（Gemini提案を採用）。
- 9話クライマックスでの拓海の沈黙：決断すべき瞬間、拓海は「決めない」「俺が決めることじゃない」等、代償の内実を説明する台詞を発しない。手が顎に向かいかけて止まる・視線を留める・沈黙を保つといった行動・非行動のみで代償を示す（Gemini案を採用。MuseSparkが提示した発話台詞案はNOT_CANON.md参照）。
- 9話記憶想起の技法：「思い出した」という説明的処理を避け、聴覚・嗅覚など感覚的要素（音・匂いのトーンの変化）を現在と過去の橋渡しに使う（Qwen提案、Geminiが実演し自己評価で問題なしと検証）。
