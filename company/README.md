# company — 会社方針・共通ルール

このディレクトリは、スタジオまあね全体に適用する方針とAI作業ルールを管理する。個別企画の進捗・原稿・作品設定はここに重複させず、各 `products/{product}/` を参照する。

## どのファイルを読むか

| ファイル | 正本として管理する内容 | 読むタイミング |
|---|---|---|
| [policy.md](policy.md) | 経営目的、優先順位、オーナー承認が必要な事項 | 全作業の開始時・重要判断時 |
| [ai-role.md](ai-role.md) | AI共通の作業開始手順、討議、成果物の扱い | AIが作業を始めるとき |
| [content-roles.md](content-roles.md) | note現行3シリーズの役割・テーマ振り分け | コンテンツの企画・分類時 |
| [ai/](ai/) | 各AIの担当領域・得意分野の目安 | AIを選ぶ・役割を依頼するとき |

## 情報の正本

- 会社の判断原則・承認：`policy.md`
- AIの作業手順：`ai-role.md`
- シリーズ戦略：`content-roles.md`
- 現行シリーズの進捗・次の行動：リポジトリ直下の [SERIES.md](../SERIES.md)
- 過去シリーズと旧企画の索引：リポジトリ直下の [SERIES-ARCHIVE.md](../SERIES-ARCHIVE.md)
- 個別企画の詳細：各 `products/{product}/` のREADME・企画資料

## 重複を防ぐルール

1. ルールの詳細は上表の正本に一度だけ記載し、他のファイルではリンクで参照する。
2. 個別企画固有の決定・状態・例外は、その企画の資料に記録する。
3. AI別ファイルは担当領域の目安に限定し、会社共通ルールを再掲しない。
4. 変更時は、関連ファイルとの矛盾がないか確認する。
