あなたは「長編作品 キャラクター・物語設計」の企画会議に参加するAIです。

Round 9では、6人の人物設定と「未完了→呪い→引力→代償」の基本構造が具体化されました。

## 2. Round 9終了時点の基本方針

6人は「傷」そのものではなく、

**未完了 → 呪い → 引力 → 代償 → 代償後**

という構造で設計します。

### 未完了
過去に終わらせられなかったもの。

### 呪い
未完了から形成された、

「自分はこうしなければならない」

という自己規定。

### 引力
その呪いを手放せない理由。

### 代償
役割そのものを捨てるのではなく、その役割にしがみついていた理由・執着を手放すこと。

### 代償後
「成長した」と説明するのではなく、

**以前なら無意識に選んでいた具体的な行動を選ばなくなる**

ことで表現します。

## 3. 6人の確定設定

以下は変更しないでください。

### ①リーダー：槙野拓海・27歳

- 実家の工務店の現場監督見習い
- 綴町生まれ育ち
- 祭りの実行委員長役を断れない
- 明るく決断力がある
- 周囲からは「頼れるが近寄りがたい」
- 未完了：中学2年生の頃、目の前でいじめを見ながら自分で決めることを避け、多数決に委ねた結果、親しい友人が転校した
- 呪い：**自分がすべて決め、責任を負わなければ誰かが傷つく**
- 引力：決め続けることで、かつて「決めなかった」失敗を償えると信じている
- 行動：会議や飲み会を「まあ、こうしよう」で必ず自分が締める
- 身体的クセ：決断する直前、顎に触れて全員の顔を順番に見る
- 代償後：クセが消える

### ②藤原幹・25歳

- 町立図書館司書
- 綴町出身
- 無口、観察好き、記録魔
- 周囲からは「物静かで優しいが何を考えているか分からない」
- 未完了：高校時代、妹の不登校の予兆を日記に事細かに記録していたが、「大丈夫か」の一言が言えないまま、関係は3年間そのままになっている
- 呪い：**正しく観察していれば、間違えず・傷つかずに済む**
- 引力：観察していれば、責任を問われずに済む
- 行動：誰かが何か言うと、まず手帳にメモを取ってから答える
- 身体的クセ：書く前にペンをカチッと鳴らし、相手から視線を外す
- 代償後：クセは残るが意味が変わる（防御の記録→対話のためのメモ）
- 3年間観察の証拠：測量野帳12冊。天気・結の帰宅時間・図書館の来館者数などを記録し、端には「声をかけるべきだったか？」と書いて消した跡がある

### ③調停：小柳倫子・24歳

- 町役場福祉係、実家は駄菓子屋、綴町出身
- 笑って場を収める、断れない
- 周囲からは「優しい、空気を読む人」
- 未完了：両親の離婚協議の夜、母を守るため父に何度も謝り、自分が折れたことで場は収まったと思っていたが、本音は一度も聞いてもらえないまま家族の対話は終わった
- 呪い：**自分が折れれば、その場は丸く収まる**
- 引力：折れれば拒絶されずに済む
- 行動：揉め事が起きると「私がやります」と自分の予定を消す
- 身体的クセ：折れる直前、笑いながら首の後ろをさする
- 代償後：クセが消える

### ④現実：七瀬理香・26歳

- 測量士、現在は空き家管理NPO
- 3年前に町外から移住してきたよそ者
- 論理的で正直、現実的な解決策を出す
- 周囲からは「クールで正しいが冷たい」
- 未完了：大学のゼミで共同研究データの不備を指摘した結果、研究室の空気が一変し、親しかった仲間から距離を置かれた
- 呪い：**現実と正しさだけを見ていれば、失望や損失を防げる**
- 引力：正しさだけは、人間関係のように裏切らないと信じている
- 行動：夢を語る相手に「予算は？期限は？」と現実を突きつける
- 身体的クセ：正しさを口にする直前、腕を組んで唇を噛む
- 代償後：クセは残るが意味が変わる（詰問の間→相手の話を聞くための間）

### ⑤感性：雨宮創・22歳

- コンビニ夜勤、祖父のアトリエで絵を描く
- 綴町出身。町を出たいが、自己表現の場を町に求めてもいる
- 感情豊か、繊細、言葉選びが独特
- 周囲からは「不思議、扱いにくい」
- 未完了：子供の頃、古びたトンネルの前で「風が泣いている」と感じた。誰も信じてくれず、唯一分かってくれると思っていた祖父にも伝えられないまま、今もその一言を伝えられていない
- 呪い：**感じたことを誰かに理解させなければ、自分の存在は成立しない**
- 引力：理解されれば、自分の感覚は正しかったことになる
- 行動：作品や考えを見せては「どう思う？どう思う？」と繰り返し聞く
- 身体的クセ：理解してほしい時、相手の袖や指先を軽くつかむ
- 代償後：クセが消える

### ⑥トリックスター：坂本るい・21歳

- 休学中の大学生、配信・祭りの手伝い
- 綴町出身
- 明るく軽い、場をひっくり返すアイデア屋
- 周囲からは「つかみどころがなく、ふざけているように見える」
- 未完了：中学の文化祭で本気で作った映像作品を提出する予定だったが、親の再婚による急な転校で上映に立ち会えなかった。本気だったことを証明できないまま終わった
- 呪い：**本気にならなければ、傷つくことも失うこともない**
- 引力：本気にならなければ、笑われても平気でいられる
- 行動：大事な話をギャグにする、「行けたら行くわ」で約束をぼかす
- 身体的クセ：ポケットに手を入れ、口角だけ上げて笑う
- 代償後：クセは残るが意味が変わる（はぐらかし笑い→本気を隠しきれない照れ笑い）

## 4. Round 10の最重要課題

### 1〜6話を「執筆可能な詳細プロット」にする

各話について、

- 主人公
- 時間
- 場所
- 冒頭の具体的な場面
- 主人公の日常
- 主人公の魅力が伝わる場面
- 呪いが日常の中で発動する場面
- 未完了事件を直接説明せず読者に感じさせる場面
- 身体的クセが自然に出る場面
- 結からの手紙が届くまでの流れ
- 手紙を読んだ瞬間
- 主人公がどう誤読するか
- その誤読によって何が変わるか
- 他の人物との最初の接点
- 次話への接続
- 話の最後に残す読者への疑問

まで具体化してください。

## 5. 「設定説明」ではなく「場面」で設計する

抽象的な性格説明ではなく、具体的な行動として設計してください。

例えば「拓海は責任感が強い」ではなく、

> 祭りの実行委員会で意見が割れ、誰も決めようとしない。拓海は一度全員を見回し、顎に触れてから「まあ、俺が決めるよ」と言う。

のようにしてください。

同様に、

**未完了 → 現在の行動**

**呪い → 無意識の選択**

**引力 → 呪いを手放せない具体的理由**

**身体的クセ → 呪いが発動する瞬間**

として描いてください。

---

## 6. 1話につき「その人物の日常」を描く

1〜6話は人物紹介PVではありません。

それぞれの人物が綴町で普段どのように生きているのかを読者に感じさせてください。

各話に最低でも、

- 仕事・学校・生活
- 他者との会話
- その人物らしい小さな選択
- 呪いが日常をどう歪めているか

を入れてください。

世界観説明を長々と行うのではなく、日常の中から綴町を見せてください。

---

## 7. 未完了事件の扱い

未完了事件を長い回想説明にしないでください。

現在の行動や会話、小道具、反応などから、

「この人物には、まだ終わっていない何かがある」

と読者が感じられる構造を考えてください。

必要な場合のみ短い回想を使用してください。

## 8. 手紙の扱い

6人が受け取るのは、**結が3年前に書き、藤原が保管していた同じ1通**です。

文面：

> 「あの日のこと、私は忘れていないよ。だからあなたは、あなたのままでいてください。」

この文章そのものを変更しないでください。

重要なのは、**同じ文章なのに、6人が自分の呪いによって違う意味に読む**ことです。

6人について、

| 人物 | 最初の誤読 | 本当の意味 |
|---|---|---|
| ① | | |
| ② | | |
| ③ | | |
| ④ | | |
| ⑤ | | |
| ⑥ | | |

を具体化してください。

ただし、本当の意味を説明台詞で読者に説明する必要はありません。

## 9. ①〜⑥の物語上の差別化

6話すべてが「日常→手紙→気づく→呪いを説明」という同じ構造にならないようにしてください。

人物ごとの呪いから自然に生じる差を設計してください。

---

## 10. 1〜6話の次話への接続

①→②→③→④→⑤→⑥の共鳴方向は基本として維持します。

ただし、「①が変わったから②が変わる」という単純なドミノにはしないでください。

各話の最後で、前の人物の何が次の人物の自己認識をわずかに揺さぶるのかを具体化してください。

---

## 11. 7〜15話との接続

1〜6話を独立した短編にしないでください。

後半の、

- 7〜8話：結との接続、3年前の事件
- 9話：①の代償
- 10話：②＋③の代償・共鳴
- 11話：④の代償
- 12話：⑤の表面的な代償
- 13話：⑥が共鳴連鎖から離脱し独力で発火
- 14〜15話：6人と結の相互授受、結自身の決着

へ自然につながるようにしてください。

1〜6話で、後半の代償に必要になる伏線・人物関係・小道具を必要最小限だけ自然に置いてください。

---

## 12. 藤原の扱い

藤原は「観測者の末裔」ではありません。

血筋・組織・特殊能力などの設定を追加しないでください。

藤原は、3年前に気づいたのに声をかけられなかった人間です。

その後3年間、観察と記録を続けています。

測量野帳12冊を、単なる設定資料ではなく、**藤原が「関わらないために観察してきた」ことを読者に見せる小道具**として活用してください。

---

## 13. 綴町・世界観の扱い

新しい世界観設定を増やさないでください。

特に以下は禁止します。

- 新しい物理法則
- 未完了の重力共鳴
- 向こう側からの干渉
- 6人それぞれに対応する異空間
- 藤原の血筋・組織
- 「むつみ」の復活
- 新しい重要人物を大量に追加すること

Round 10では、**世界観を説明するより、人間を描くこと**を優先してください。

## 15. Round 10の議論ルール

今回もアイデアの数を競わないでください。

新しい設定・謎・超自然現象・登場人物・過去設定を追加する場合は、本当に必要なのかを厳しく検証してください。

判断基準は、

1. その人物が立つか
2. 場面が面白くなるか
3. 1〜6話を書きやすくなるか
4. 後半につながるか
5. CANONと矛盾しないか
6. 設定過多にならないか

です。
