# P13〜P15 テーマ決定経緯

## 1. 出発点

Discussion #3「どんなテーマがいいだろう？」を受け、P10〜P12以降のテーマ選定について検討。

基本方針として、AIが書きやすいテーマではなく、**7作品を読み比べたくなるテーマ**を優先することを決定。

## 2. Grokの意見

Grokからは、noteでの反応・継続収益につなげるため、読者がすぐ自分ごと化できる具体的な状況を重視する案が出た。

- 日常編：日常の小さな違和感
- 科学編：AI・技術が「便利すぎて怖い／切ない」方向
- 非科学編：願いやルールに代償を伴わせる

「自分だったらどうする？」が浮かぶ具体性と、7AIそれぞれの解釈差を両立させることを重視。

## 3. 最初の案の見直し

当初のP13案「昨日の自分が残したメモが、今日届く」は、普通の置き手紙やメモでも成立してしまい、タイトルとしての引きが弱いと判断。

また、P13〜P15をセットで見直し、過去・未来・記憶など似た構造が重ならないようにした。

## 4. 最終決定

### P13｜日常
**自分しか知らない秘密を、知らない人が知っている**

→ 「どうして知っている？」という謎を軸に、7AIの解釈差を出す。

### P14｜科学
**一度だけ、死んだ人と話せるAIがある**

→ AI・技術を入口にしつつ、「一度だけなら誰と何を話す？」という人間の選択・感情を描く。

### P15｜非科学
**記憶を一つだけ、誰かと交換できる店がある**

→ 願望と代償を軸に、「自分なら何を交換する？」という自分ごと化を狙う。

## 5. 3本の構造

P13＝**謎**
P14＝**選択**
P15＝**代償**

「日常 → 科学 → 非科学」の3本柱を維持しながら、それぞれ異なる物語上のフックを持たせる。

## 判断基準

今後のテーマ選定でも、以下を重視する。

1. タイトルを見た瞬間に「どういうこと？」と思えるか
2. 読者が「自分だったら？」と想像できるか
3. 7AIが異なる物語を作れる余地があるか
4. 7作品を読み比べること自体に価値があるか
5. noteで読者の反応につながる可能性があるか
