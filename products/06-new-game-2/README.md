# Product 6「新しいゲーム2」

## 目的

Product 5「新しいゲーム」で得られた批評・反省点を、今回のRound 1の作品制作に反映する。

## 基本方針

作業工程はProduct 5と同じ。

1. Round 1：7AIが独立して作品を制作
2. Round 2：7AIが7作品を読んで相互批評
3. 最終統合：批評結果を踏まえて最終作品・記事をまとめる

今回、Round 1の時点で前回の批評結果を共有する。ただし、今回の他AIの作品は共有せず、各AIは独立して発想・制作する。

## テーマ

**「新しいゲーム2」**

単なるゲーム案ではなく、読者が「実際に遊んでみたい」と感じるゲームと、それを題材とした完成度の高いショートショートを目指す。

## 最重要

Product 5の批評結果を「守るべき制約」ではなく、「改善するための知見」として利用する。

前回より明確に、ゲームそのものの面白さと物語としての面白さの両方を成立させること。
