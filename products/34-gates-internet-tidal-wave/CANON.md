# P34 CANON：『インターネットは津波だ』——ビル・ゲイツが「最優先」を書き換えた日

最終更新：2026-10-25（タイトル・価格を決定）

## 企画の核

- 企画名：『インターネットは津波だ』——ビル・ゲイツが「最優先」を書き換えた日
- 主題：1995年5月26日、ビル・ゲイツが経営幹部と直属の部下に送った社内メモ「The Internet Tidal Wave」。当時のマイクロソフトは PC の OS とオフィスソフトで絶頂にあったが、ウェブの上では存在感がなく、ブラウザの主導権は創業1年の Netscape が握っていた。メモはインターネットを「1981年の IBM PC 以来、最も重要な出来事」と位置づけ、全製品計画の書き換えを命じた。中心は、勝っている会社がなぜ変化に遅れるのか、そしてトップの「格上げの宣言」が組織をどう動かしたのかという構造の分析である。
- 中心テーマ：環境変化の「最優先」への格上げ。変化を自分の目で実測すること、競合を格付けすること、全計画への波及を命じること、責任者と期限を名指しすること——この一連の手順を、読者が自分の事業を点検する実践フレームワークに翻訳する。
- P33との関係：P33が「一つの決定が覆る構造」（組織の意思決定）を描いたのに対し、P34は「一つの文書が組織を動かす構造」（トップの宣言と実行）を描く。P32の「一つの質問」ともども、文書・言葉が転換点になる系譜の一編。

## 編集の基本方針

- **事実を偽らない**：日付・役職・数値は fact-check.md の基準に基づく。各項目には確認区分（一次資料／二次資料（複数）／二次資料（単一）／未確認）を付け、区分の弱い項目は本文で幅を持たせた表現にするか扱わない。
- **引用の扱い**：メモ原文の引用は、公開された原文に基づき、和訳して引用する。翻訳は意味を変えない範囲で平易にし、主要な言い回しは英語の原句を併記する。
- **俗説を断定しない**：ゲイツの1993年「インターネットには興味がない」発言とされるものは出所が不確かなため本文では扱わない（fact-check.md に未確認として記録）。アンドリーセンの「デバイスドライバ」発言は、本人の発言として広く引用されるが、本文では帰属を明示して扱う。
- **人を傷付けない**：実在人物の内面・動機を創作しない。ゲイツを「先見の明の英雄」にも「独占者」にも単純化せず、勝ち筋の内側にいた王者が前提を書き換えた過程として描く。Netscape 側も「敗者」としてではなく、新しい土俵を作った側として描く。
- 文体は P30〜P33 にそろえる（常体、短い段落、ドキュメンタリー調）。公開文に内部名「スタジオまあね」は入れない。原稿内に作業場所（GitHub・ファイル名等）への参照は入れない。

## 事実関係の基準

- 時系列：1993年 Mosaic 公開 → 1994年1月 アラードの社内メモ → 1994年4月 Netscape 創業（当初 Mosaic Communications）→ 1994年12月 Navigator 1.0 → **1995年5月26日 ゲイツのメモ** → 1995年8月9日 Netscape の IPO → 1995年8月24日 Windows 95 と MSN 開始、IE 1.0 は Plus! パック → **1995年12月7日 Internet Strategy Day（IE 無料化の公表）** → 1998年5月18日 米司法省らが提訴 → 1998年11月24日 AOL が Netscape 買収を発表（約42億ドルの株式交換）→ 1999年11月5日 事実認定 → 2001年 和解の方向へ。
- 数字の扱い：Navigator のシェア「70%」はメモ原文の記述（ゲイツ自身の認識）として扱う。Netscape の IPO（公開価格28ドル、初日終値58ドル台、時価総額 約29億ドル）と AOL の買収額（発表時 約42億ドル、完了時は AOL 株上昇で膨らんだ）は報道ベースとして明示する。
