# 『インターネットは津波だ』（仮）導入　1995年、王者のいない場所

*世界最大のソフトウェア会社が、次に来る時代の地図に載っていなかった*

## 1995年5月、絶頂の会社

1995年の春、マイクロソフトは絶頂にあった。

パソコンのOSでは Windows が世界の標準になり、Office はビジネスソフトの代名詞になった。創業から20年。共同創業者のビル・ゲイツは39歳で、この1995年に初めて世界一の富豪となる。

8月には、満を持して Windows 95 が発売される。深夜販売と行列が予告されるほどの、空前の看板製品だった。

ところが、その絶頂の会社の存在感が、ほとんど感じられない場所があった。

インターネットである。

## ウェブの上に、マイクロソフトはいなかった

1993年、画像を表示できるブラウザ Mosaic が公開され、ウェブは研究者の道具から、一般の人の目に触れる場所へと広がり始める。

1994年、その開発者の一人だったマーク・アンドリーセンらが Netscape を創業し、ブラウザ Navigator を公開した。速くて使いやすい Navigator はまたたく間に広がった。ゲイツは自らのメモに、Navigator の利用シェアは70%と記している。

この新しい場所で、マイクロソフトの影は薄かった。

ゲイツ自身が、メモの中でこう書いている。自ら10時間、ウェブを閲覧して回った彼は、こう記した。

「10時間ブラウジングして、Word の文書（.DOC）も、動画（AVI）も、Windows のプログラム（.EXE）も、1つも見なかった。目に入ったのは、QuickTime の動画ファイルばかりだった」

動画の形式は、他社（Apple）の QuickTime が標準になっていた。文書の形式でも、Adobe の PDF が「標準の代替形式」として広がっていた。どちらもマイクロソフトの形式ではなかった。世界のソフトウェアの王者がいない場所で、インターネットの標準は静かに決まりつつあった。

しかも Netscape の狙いは、ブラウザのシェアだけではなかった。アンドリーセンは、やがて Windows は「出来の悪いデバイスドライバの寄せ集め」に成り下がるだろう、と言ったとされる。ブラウザがアプリケーションの土台になれば、その下にある OS は、誰のものでも構わない部品になる。マイクロソフトの王座そのものを、無価値化する構想だった。

## 王者の賭けは、別の場所にあった

マイクロソフトが無策だったわけではない。同社は MSN という独自のオンラインサービスを準備していた。Windows 95 の発売と同時に立ち上げ、会員制の閉じたネットワークの中で、情報も買い物も完結させる。既存の大手オンラインサービスと正面から競う構想だった。

つまり王者は、「開かれたインターネット」ではなく「自分たちの庭」を、次の主戦場だと読んでいた。

社内には、違う読みをする者もいた。1994年1月、社員の J・アラードは「Windows――インターネットにおける次のキラーアプリケーション」と題する社内メモを書き、インターネットこそ本丸だと訴えている。だが、会社全体の重心はまだ動いていなかった。

ゲイツ自身も例外ではなかった。彼はこの後に出すメモの冒頭で、インターネットの重要度の見立てを「何段階も引き上げてきた」と率直に書いている。王者でさえ、時代の変化の前では、段階的にしか目を覚まさなかったのである。

当時、世界のインターネット利用者は数千万の規模。それでも増え方は尋常ではなかった。利用者が増えれば中身が増え、中身が増えれば利用者が増える。その循環が、回り始めていた。

## 1995年5月26日

そして、1995年5月26日。

ゲイツは、経営幹部と、その直属の部下たちに宛てて、一通の社内メモを送った。

件名は「The Internet Tidal Wave」。インターネットの津波。

その中で彼は、インターネットへの評価を「最高レベル」に引き上げたと宣言した。それは「1981年の IBM PC の登場以来、最も重要な出来事」であり、「GUI の到来よりも重要だ」とまで書いた。

絶頂にある会社のトップが、自社の勝ち筋の前提を、自らの言葉でひっくり返す文章だった。

この一通は、会社の何を変えたのか。

なぜ、これほど強い会社が出遅れたのか。そしてメモの実行は、その後の3年間で、競合の運命と——会社自身の運命までも、どう変えていったのか。

## この先で読めること

事件の全貌
- メモの検証：ゲイツが書いた「格上げ」の宣言、競合の格付け、そして驚くほど具体的な命令の中身
- わずか半年あまり後の1995年12月7日、マイクロソフトが取った大転換と、ブラウザ戦争の帰結
- 皮肉な結末：あのメモの言葉が、後に会社を訴える側の証拠になったこと

自分の事業への応用
- 実践フレームワーク「津波の点検」：環境の変化を「最優先」に格上げするための5つの手順
- 記入例つきのワークシート：自分の事業にとっての「津波」を特定し、格上げすべきかどうかを判断する材料をそろえる
