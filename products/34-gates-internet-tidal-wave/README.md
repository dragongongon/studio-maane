# P34：『インターネットは津波だ』（仮）

1995年5月26日、絶頂にあったマイクロソフトのトップ、ビル・ゲイツが経営幹部に送った社内メモ「The Internet Tidal Wave（インターネットの津波）」。自社の勝ち筋の前提を覆し、インターネットを「最優先」に格上げしたこの一通が、半年後の大転換、Netscape の崩壊、そして皮肉にも会社自身への反トラスト訴訟の証拠へとつながっていく過程を描く note 企画。P30〜P33に続く「歴史的転換点」シリーズの一編として、物語として面白く、しかし事実を偽らずに、環境変化を「最優先」に格上げする点検を自分の事業に持ち帰れる実用パートを備える。
