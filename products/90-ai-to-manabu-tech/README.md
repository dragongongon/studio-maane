# AIと学ぶ技術

## 目的
生成AIを実際の作業で使い、役立った手順・運用上の工夫を読者が再現できる形で紹介するnoteシリーズ。

## 想定読者
複数の生成AIを使って調査・企画・執筆・開発を進めているが、会話や決定事項の管理に手間を感じている人。

## 執筆方針
- 実際に試したことを中心に書き、確認済みの事実と個人の経験・提案を区別する。
- 特定のツールやファイル構成を必須と誤解させない。
- 無料・低コストで始められる方法を優先する。
- 公開前に手順の再現性、リンク、個人情報、誤解を招く表現を確認する。
- noteへの外部公開はオーナー承認後に行う。
