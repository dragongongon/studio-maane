## 目的
外部で語られるAI副業・note収益化の手法を、小さなサイクルで実行し、できた記事をnoteに公開するシリーズ。

「誰でも簡単に月○万円」系の主張をそのまま信奉せず、読者が「自分でも試す価値があるか」を判断できる材料を提供する。

**定義**：先に実験、後に検証。  
- **実験**：外部手法を小さく回し、記事にしてnoteへ公開すること（公開された記事そのものが実験）  
- **検証**：公開後、しばらくしてから閲覧・スキ・購入などの数字を見ること  
実験を設計／市場の二段階には分けない。売上がない段階を検証完了のように書かない。

**方針**：外部SNSでの定期告知を必須にしない。note内の露出を主な入口にし、「書く→公開→（しばらく後に）数字を見る→1点直す」を低負荷で回す。

役割の正本は `company/content-roles.md`。
