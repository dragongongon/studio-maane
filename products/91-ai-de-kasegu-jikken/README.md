# AIで稼ぐ実験

## 目的
人気のAI副業・note収益化手法（穴場ジャンル発掘、ペルソナ1人絞り、地雷回避、有料note構成など）を実際に試し、過程・数字・失敗を一次情報として公開するnoteシリーズ。

「誰でも簡単に月○万円」系の主張をそのまま信奉せず、再現性・支払意思・コストを検証する。読者が「自分でも試せるかどうか」を判断できる材料を提供する。

**方針**：外部SNSでの定期告知を必須にしない。note内の露出（検索・関連・シリーズ継続）を主な入口にし、「書く→公開→数字を見る→1点直す」を低負荷で回す。

## 進め方（2026-10-13）
- **GrokとMuseSparkの2ルートで進める。**
- **Grok**は手法の構造化・批判的評価・改善案・実験方法の検討を担う。
- **MuseSpark**はSNS・公開情報から収益化手法を発見し、出典と主張を検証し、候補比較・実験計画・実行記録・記事草稿を担う。SNS探索が得意という想定も、実際の調査品質で検証する。
- MuseSparkはGrokの既存実験を差別化なく繰り返さず、補完的な検証価値を優先する。
- **「AIと学ぶ技術」とは別路線**。学ぶの反応・テーマ・公開順には依存しない。
- 次の記事は、本シリーズ自身の数字（閲覧・スキ・購入など）と実験結果で決める。
- 他シリーズと共通なのは姿勢（誇張しない・過程を出す）のみ。ネタ連動・相互リンクは必須にしない。

## 想定読者
- AI副業やnote有料記事に興味があるが、「また情報商材か」と疑っている人
- AIへの指示テンプレを試したが成果が出ず、何が足りないのか知りたい人
- 実績ゼロの状態から小さく検証したい人
- 毎日の告知作業なしで続けたい人

## 執筆方針
- 実際に試した過程・判断の根拠・数字を中心に書く。推測と確認済みを区別する。
- 誇張した収益数字を出さない。失敗や「売れなかった理由」も隠さない。
- 無料代替や競合の存在を明示する。
- 公開・有料販売はオーナー承認後に行う。
- タイトル接頭語は「AIで稼ぐ実験」とする。
- 特定の発信者名・特定プラットフォーム・特定AI製品への紐づけは避ける。ただし、検証上必要な事実の記載は妨げない。
- 外部告知は後付け可能な設計にし、必須工程にしない。
- 調査だけの段階と実際に実行した実験を明確に区別する。
