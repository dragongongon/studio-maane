# AIで稼ぐ実験

## 目的
人気のAI副業・note収益化手法（穴場ジャンル発掘、ペルソナ1人絞り、告知文設計、有料note構成など）を、スタジオまあねの多AI体制で実際に試し、過程・数字・失敗を一次情報として公開するnoteシリーズ。

「誰でも簡単に月○万円」系の主張をそのまま信奉せず、再現性・支払意思・コストを検証する。読者が「自分でも試せるかどうか」を判断できる材料を提供する。

## 想定読者
- AI副業やnote有料記事に興味があるが、「また情報商材か」と疑っている人
- ChatGPTなどの指示テンプレを試したが成果が出ず、何が足りないのか知りたい人
- 実績ゼロの状態から小さく検証したい人

## 執筆方針
- 実際に試した過程・判断の根拠・数字を中心に書く。推測と確認済みを区別する。
- 誇張した収益数字を出さない。失敗や「売れなかった理由」も隠さない。
- 無料代替や競合の存在を明示する。
- 多AIの意見対立や人間の最終判断過程を一次情報として活かす（P01・P02の延長）。
- 公開・有料販売はオーナー承認後に行う。
- タイトル接頭語は「AIで稼ぐ実験」とする。
- 特定の発信者名・特定プラットフォームへの紐づけは避ける。

## 既存資産との関係
- P01「AI副業は本当に稼げるのか？」・P02「AIと一緒に書いた記事を売りたい話」の実験姿勢を引き継ぐ。
- 「AIと学ぶ技術」が「どう運用するか」なら、本シリーズは「どう収益化を検証するか」を扱う。
- よく言われるChatGPTへの指示順（穴場→ペルソナ→告知文→地雷→note設計→改善）を参考にしつつ、スタジオ仕様に最適化する。
