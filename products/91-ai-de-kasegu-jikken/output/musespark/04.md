# P91 実験計画書
作成日: 2026-10-13
担当: MuseSpark
採用手法: 候補B Threads→無料note→有料note 0→1導線設計（300円テスト）

## 1. 検証したい仮説
- 仮説H1: noteで「有料」絞込検索して需要が確認できるテーマ（例: note副業0→1、AI×note、Threads集客）について、読者を1人に絞り無料noteで共感・判断材料を提供すれば、300円の有料noteでも0→1（初回購入）が発生する
- 仮説H2: Threadsでの事前集客（1日1投稿、固定ポスト経由の導線）有無で、有料noteのPVと購入率に差が出る
- 仮説H3: 無料部分30%で「問い」を立て、有料部分で「すぐ使えるテンプレ・チェックリスト」を提供する構成は、無料部分で結論を全て書く構成より購入率が高い（過去の失敗談 hamaken氏指摘の検証）

## 2. 対象顧客
- メインペルソナ: noteで有料化に挑戦したが1件も売れず止まっている20-40代副業初心者。文章力・実績・フォロワー数がないことを不安に思っている。
- サブ: Threadsで発信を始めたいが何を書くか迷っている人
- 除外: 既に月1万円以上稼いでいる中上級者、エンタメ小説目的の読者

## 3. 具体的な実施手順（最小実験）

### Phase 0: 需要検証（30分）
- noteで「AI note副業」「note 0→1」「Threads 集客」などを検索
- 有料記事に絞り込み、上位20件のタイトル・価格・スキ数・内容をスプレッドシートに記録
- 価格中央値と無料/有料境界の位置をメモ

### Phase 1: 無料note 2本作成（計2時間）
- 無料記事1: 自己紹介＋失敗前提の実験宣言「AIで稼ぐ実験 P91 参加記録：0件から始める」
    - 目的: 信頼貯金、P91方針の透明性提示
- 無料記事2: 需要検証結果共有「有料noteで本当に売れているのは何か 20本調べて分かったこと」
    - 構成: 誰向けか→先に結論→理由→今日できる一手順→失敗しやすい点（ゆるサポ型）
    - SEO: タグ「#AI副業 #note副業 #0→1」

### Phase 2: 有料note 1本作成（計3時間、最小版）
- テーマ: 「note 0→1チェックリスト：Threads→無料→有料の導線を1日で作るための7項目」
- 価格: 300円（テスト価格、手数料考慮で手取り約255円）
- 構成:
    - 無料30%: このnoteで何が解決するか（初回購入が出ない原因4つ）、使い方、全体像、現状診断ワーク（1問）
    - 有料70%: 
        - ①読者1人定義シート（記入例付き）
        - ②需要検証手順（スクショ付き）
        - ③無料/有料境界の分け方テンプレ
        - ④Threads固定ポスト文面テンプレ
        - ⑤7日間チェックリスト
- AI使用範囲: 構成案・タイトル案出しにClaude/ChatGPTを使用、体験談・検証結果は人間が記述（AIを参謀として使う方針）

### Phase 3: 集客導線設置（30分）
- Threads固定ポスト作成: 「noteで0→1できなかった人向けにチェックリスト作りました」+ 無料noteリンク
- Threads通常投稿 7日間: 1日1投稿、学び小出し、最後に固定ポスト誘導
- Xは今回は実施せず（変数絞るため）。note内タグと関連記事リンクは設定

### Phase 4: 測定（7日間）
- 毎日PV、スキ、フォロワー、Threadsインプ、クリック、購入数、売上を記録
- 無料部分の離脱推定: スキ率、最後まで読んだ率（note解析）

## 4. 使用サービス・ツール
- note（無料アカウント）
- Threads（既存アカウント @tsoulala 想定、スタジオまあね用に新規作成も可）
- Claude 3.5 / ChatGPT（無料プラン）
- Googleスプレッドシート（記録用）
- 費用: 0円（AI有料版は未使用）

## 5. 必要費用と作業時間見積もり
- 費用: 0円
- 作業時間: 合計約6時間（検証0.5h + 無料2h + 有料3h + 導線0.5h）+ 運用7日間で1日10分
- 外部委託: なし

## 6. 成果を判断する指標
- 主要KPI: 初回購入1件発生（0→1達成）までの日数、購入数
- 副次KPI: 
    - 無料note2本のPV、スキ率
    - 有料noteのPV、購入率（購入÷PV）
    - Threadsインプ、プロフィールクリック、固定ポスト経由流入
    - 無料部分の構成による差（今回は1パターンのみだがログとして記録）
- 定性: 購入者の反応、コメント、スキの質

## 7. 成功・失敗判断基準
- 成功（最小）: 7日以内に1件以上売れる（売上300円、手取り約255円）。月1万円目標への第一歩として再現条件を特定できる
- 成功（理想）: 7日で3件以上（900円）、Threads経由流入が全体の50%以上、無料note経由の購入が確認できる
- 失敗: 7日で0件。ただし失敗も一次情報として価値あり。原因を「テーマ」「無料部分」「導線」「価格」のどれと推定できるかを記録
- 打ち切り基準: PVが7日で10未満の場合は集客不足と判断、Threads投稿内容を改善して再実施

## 8. 実行できない場合の代替案
- noteアカウントが用意できない場合: 下書きMarkdownまで作成し、構成・テンプレの検証価値のみを記事化（実践検証ではなく調査記事として区別）
- Threads投稿が規約で不可の場合: note内回遊（関連記事リンク、タグ）のみで検証
- AI使用が制限される場合: 全て手動で作成、所要時間増を記録

## 9. オーナー承認が必要な作業
- 要承認:
    - [ ] note有料記事の公開（300円設定）と販売（金銭発生を伴うため）
    - [ ] Threads / X などSNSへの投稿（外部公開に該当）
    - [ ] 有料サービス（Claude Pro等）への課金（今回は不要だが、必要になった場合）

- 承認不要で実施可能:
    - 公開情報の調査、スプレッドシート作成、下書き執筆、構成案作成（ローカル保存）

## 10. P91方針との整合性チェック
- 「誰でも簡単に稼げる」を信じない: Instagram大量生産手法は不採用、0件失敗を前提に設計
- 再現性・支払意思・費用対効果検証: 300円テスト、需要検証、支払理由（時短テンプレ）を明確化
- 成功だけでなく失敗も記録: 7日間0件でも「未計測」とせず実測値を記録、原因推定を分離
- 確認済み情報・主張・推測・結果を区別: 売上は自己申告ではなくnote管理画面の実測値のみ使用、公式GMV等の数値は出典明記
- 無料代替を隠さない: 無料部分で価値提供、有料は完成品テンプレと明記
- 根拠なき売上を作らない: スクショ加工なし、手数料考慮
