# P91 実験計画 | MuseSpark | 2026-10-13

**Path想定:** `products/91-ai-de-kasegu-jikken/output/musespark/02-experiment-plan.md`
**対象候補:** 候補A「過程を晒す」記録販売設計（こまめ社長型）＋ 候補Bの無料部分5要素を組み込み
**実験区分:** 設計実験A（公開前）

## 1. 仮説と対象顧客

**仮説:**
- 外部で語られる「1本の有料noteを育てる」「過程を晒すと実績ゼロでも買われる」という主張は、スタジオまあねの条件（AIチームの実験ログを素材にする）でも、無料=考え方・有料=手順とテンプレという役割分担と、5項目フレームで記録を整理すれば、読者が「自分でも試す価値があるか判断できる材料」になると評価される。
- 売上実績がない段階でも、設計過程・失敗・コスト・再現条件を明示することで、無料部分の離脱を減らせる。

**対象顧客:**
- noteで0→1を作りたいが「何を書けばいいか」「無料と有料をどう分けるか」で止まっている20-40代副業初心者
- AIを使っているが、結局自分の作業も多く、過程をどう見せるか悩んでいる人（よりみち記事のターゲットに近い）[^1]

## 2. 実行手順と使用ツール

**手順（承認不要範囲のみ）:**
1. 既存P91資料の整理（README, Grok出力の要約）- 1h
2. 外部手法の出典・主張・根拠・限界の分離表を作成 - 完了（00-research-log.md）
3. 候補比較評価 - 完了（01-method-comparison.md）
4. **今回の設計実験A:**
   - a. テーマを1つ選ぶ: 「外部の『1本育てる型』をP91条件で回したらどうなるか」
   - b. 無料部分2パターン作成（内部草稿、公開前）:
     - パターン1: 過程を晒す型（5項目フレーム: やったこと・なぜ・何が起きた・学び・次）
     - パターン2: 稼ぎ方を教える型（従来型、比較用、採用しないが設計比較のため作成）
   - c. 無料部分の5要素チェック（誰に・何が得られるか・何が入っているか・どう伝えるか・橋渡し1行）を両パターンに適用
   - d. 有料部分の線引きを定義: 有料=手順の具体化・再現条件・失敗・直し方候補3つ・テンプレ（P91ブリーフ「書いてよいこと」準拠）
   - e. 価格仮置き: ¥300-¥980帯で3案作成（確定はオーナー承認後）
   - f. 測定設計: 閲覧・スキ・滞在・無料→有料遷移の想定測定方法を定義（未測定の段階では数字を捏造しない）
5. 記事草稿作成: タイトル接頭語「AIで稼ぐ実験」＋副題「過程を売る型をP91で回してみた（設計実験）」

**使用ツール:**
- GitHub (studio-maane) - 共通情報源
- Markdownエディタ
- 検索: browser.search / meta_1p.content_search（実施済み）
- 費用0のツールのみ: Google Docs, Canvaは使用しない（承認前は外部サービス登録回避）

## 4. 測定指標と測定方法

**設計実験A（公開前）の指標:**
- 手順の具体性: 第三者が読んで再現できるか（内部チェックリスト）
- 無料/有料の役割分担の明確さ: 無料部分を読んで「有料で何が得られるか」が1文で言えるか
- 再現条件の明示: 時間・費用・スキル・必要な環境が書かれているか
- 未測定の明示: 売上・部数がない段階で「未測定」と書けているか（P91ブリーフ遵守）

**市場実験B（公開後、承認後）の指標 - 今回は設計のみ、測定は将来:**
- 閲覧数、スキ数、スキ率、滞在時間、無料→有料遷移率、購入数、返金率
- 測定方法: noteダッシュボードの「アクセス状況」スクショ（¥15,170,720のような事例は発信者申告であり、一次証拠として扱う際は期間・対象を明記）
- **現段階ではBの数字は「未測定」と記録する。実施済みの検証完了のように書かない。**

## 5. 成功・失敗の判定基準

**設計実験Aの成功基準:**
- 出典・主張・根拠・限界を分離した記録が残っている
- 無料部分2パターンが「過程を晒す」vs「稼ぎ方を教える」で対比できている
- 有料部分の線引き、価格仮置き3案、無料代替との差が明記されている
- 記事草稿が「AIで稼ぐ実験」接頭語で、未公開なのに売れたように書いていない

**失敗基準:**
- 候補の主張をそのまま事実として扱っている
- 未測定の数字を捏造している
- チェックリスト販売単体になって「外部型を回した結果」に接続できていない
- Grokの指示順実験と差別化なく重複している

**市場実験Bの成功基準（将来）:**
- 月1万円の継続収益に近づく材料が得られたか（1部でも売れれば学習になるが、1部で成功と誇張しない）
- 失敗も含めて再現条件が記録できたか

## 6. 無料代替・競合

- **無料代替:** 
  - note公式「500記事タイトル分析」のガイド
  - こまめ社長の無料部分のチェックリスト[^2]
  - 自分で過程を無料noteに書く
- **有料との差:** 
  - 無料は考え方まで。有料は「うちの条件（AI7人チーム、GitHub運用、費用0）で回した時の手順・失敗・直し方候補3つ・再現条件・テンプレ」まで具体化
  - 時間短縮: 読者が同じ実験を0から設計する時間を省ける
