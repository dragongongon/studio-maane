# Product 19：ユニット編（作業名）

## 作品概要

Product 16『届かなかったもの』のスピンオフ作品（Product 17『残された輪郭』、Product 18『育ったかたち』に続く）。題名は未定。

6人（槙野拓海・藤原幹・小柳倫子・七瀬理香・雨宮創・坂本るい）の過去を、2人1組（3ユニット）で並べて描く。全6話、1話1人。

- ユニットB＝創×るい（第1・2話）
- ユニットC＝拓海×理香（第3・4話）
- ユニットA＝藤原×倫子（第5・6話）

## 企画目的

6人が「今のこの人」になった過去を、2人ずつ並べる。2人が過去に関係していたのではなく、読者の視線の中で2人の過去が並ぶことで「同じ形」（物・仕草・時期）が見える構造とする。

## 基本方針

- 各話は、守りのルール（呪い）が「うまく効いた」瞬間で終える。その時点では合理的で、自分を守ることに成功した自己規定として扱う。
- 各ユニットの2人は、同じ日・同じ出来事の中で短く関わる場面を共有する（2026-09-29、Dragon決定）。一方の行動が他方の結果を実務的に左右する構造は作らない。
- 各話の場面は、Product 18の確定場面より後に置く。
- 短め・テンポ重視。1話の文字数は増やさず、話数で分量を調整する。
- 結は登場させない。反転は、地の文で解説せず、行動と沈黙だけで示す。
