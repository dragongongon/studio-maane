# Product 19：似ていた手つき

## 作品概要

Product 16『届かなかったもの』のスピンオフ作品（Product 17『残された輪郭』、Product 18『育ったかたち』に続く）。題名は『似ていた手つき』。

6人（槙野拓海・藤原幹・小柳倫子・七瀬理香・雨宮創・坂本るい）の過去を、2人1組（3ユニット）で並べて描く。全6話、1話1人。

- ユニットB＝創×るい（第1・2話）
- ユニットC＝拓海×理香（第3・4話）
- ユニットA＝藤原×倫子（第5・6話）

## 企画目的

6人が「今のこの人」になった過去を、2人ずつ並べる。各ユニットの2人は、その過去の時点で互いに積極的に関わっており（P16で6人が集まった際に、自然に振る舞える土台）、その中で「同じ形」（物・仕草・時期）が読者に見える構造とする。

## 基本方針

- 各話は、守りのルール（呪い）が「うまく効いた」瞬間で終える。その時点では合理的で、自分を守ることに成功した自己規定として扱う。
- 各ユニットの2話は、同じ日の続き（リレー）。2人は会話・手伝い・同行・差し入れなどで関わるが、相手の呪いを解いたり、問題を実務的に解決したりしない（2026-10-02、Dragon決定）。
- 各話の場面は、Product 18の確定場面より後に置く。
- 短め・テンポ重視。
- 結は登場させない。反転は、地の文で解説せず、行動と沈黙だけで示す。
