# 『「1万分の1」の手は、2つあった』有料パート　2つの手を確かめる ― 棋譜と検証台帳

無料記事では物語として追ってきた2つの手を、ここでは「棋譜」という記録の側から読み直す。囲碁のルールを詳しく知らなくても、着手の座標と勝率の動きを追うだけで、なぜこの2手が特別だったのかを自分の目で確かめられるようになる。

あわせて後半では、この記事自体が伝説的な逸話をどう検証してきたか——「神の一手」といった語られ方を鵜呑みにしないためのチェックリスト——を公開する。AI時代の「すごい話」全般に応用できる手順だ。

## 1. 棋譜の座標の読み方

囲碁の棋譜は、19×19の盤面を座標で記録する。

- 横軸はアルファベットの A から T（ただし I は数字の1と混同しやすいため飛ばす）
- 縦軸は数字の 1 から 19
- たとえば「P10」は、左から15列目・下から10行目の交点だ（I を飛ばす約束のため、P は15列目になる）

この約束さえ分かれば、世界中の棋譜データベースで、あらゆる名局を同じ形で再現できる。

なお、縦軸は下から数える国際標準の表記だ。上から数える棋譜ソフトでは、L11は上から9行目にあたるが、P10はどちらでも10行目になる。また、19路盤では右端のTを19列目と数えると、内側から5本目の線がP列にあたり、盤の中心（天元）はK10で、L11はその右上隣にあたる。

## 2. 第37手＝黒の P10

第2局、AlphaGo（黒）の37手目は、座標でいうと **P10** だった。AlphaGo にとって19番目の石だ。

局面を大まかに言うと、右辺で白の石が寄ってきている場所に、黒が五路の位置から「肩」を衝いた形だ。

- 古典的なセオリーでは、序盤の五路は「地に結び付きにくく、効率が悪い」とされる
- だからこそ、プロの解説者の第一感は「ミスではないか」だった
- ところが AlphaGo は「点差」ではなく「勝率」を最大化する設計のため、人間の感覚では「緩く見える手」でも、勝率が最も高いなら選ぶ

実際この第2局では、終盤の167手目にも「明らかなミスに見える手」が現れ、解説者を困惑させた。アン・ヨンギル（安永吉）八段はこれを勝利宣言のようなものかもしれないと評したと伝えられている。点差を広げるのではなく、負ける可能性を消していく——第37手の「理解しにくさ」の正体は、この設計思想の違いにある。

## 3. 第78手＝白の L11

第4局、李世乭（白）の78手目は、座標でいうと **L11** だった。盤のほぼ中央だ。

この手は「ワリコミ」——黒石と黒石の間に白石を割り込ませ、黒の連結を脅かしながら自軍の連絡を図る手筋だった。手筋そのものは基本形だが、問題は「この局面で、それが成立するかどうかは、膨大な変化を読まなければ分からない」という点にある。

AlphaGo の反応を、勝率の数字で追うとこうなる。

| 時点 | AlphaGo の自己評価 |
| --- | --- |
| 79手目（第78手を受けた直後） | 勝率 約70%（評価値はまだ AlphaGo 優位） |
| 87手目 | 評価が急落し始める |
| 87〜101手 | 普段は見られない悪手が連続 |
| 92手目まで | 李が形勢を逆転 |
| 180手目 | AlphaGo が投了（勝率の自己評価が20%の閾値を下回った） |

ポイントは、78手の直後には、AlphaGo の評価値に異変がまだ表れていなかった、という点だ。解説者のデイビッド・オルメロドは、探索の過程で「起きにくい変化筋」が枝刈りされ、その先にあった重要な変化が探索のレーダーの外に置かれた、と分析している。DeepMind 自身も後に、自分たちにも分からない弱点が AlphaGo にあり、李がそれを突いた、という趣旨を述べている。第78手は、その弱点が盤上に現れた一手だったと言える。

なお、後の検証では、第78手そのものがただちに黒を追い詰める絶対手だったわけではなく、直後の第79手（黒K10）の応手ミスが逆転の直接の引き金になったとされる。ただ、その応手ミスを誘ったのは、第78手が作り出した複雑な変化だった。

参考までに、全5局の手数と勝敗は次のとおりだ。

| 局 | 手数 | 勝者 |
| --- | --- | --- |
| 第1局 | 186手 | AlphaGo |
| 第2局 | 211手 | AlphaGo |
| 第3局 | 176手 | AlphaGo |
| 第4局 | 180手 | 李世乭 |
| 第5局 | 280手 | AlphaGo |

## 4. 伝説を検証するチェックリスト

第37手と第78手の物語は、10年の間に何度も語り直され、その過程で少しずつ「盛られて」きた。この記事の執筆で実際に起きた例とともに、検証の手順を示す。

1. **一次の記録に当たる**：棋譜・対局データ・本人の発言記録など、元の記録を確認する（今回は、棋譜は対局データに当たり、DeepMind の公式解説と2016年当時の報道を土台に、Wikipedia の対局ページを補助として使った。Nature 論文は、AlphaGo の仕組みの説明の根拠に限って参照している）
2. **「誰が言ったか」を確かめる**：「神の一手」と評した古力九段の発言は、当初あちこちで第37手への評として紹介されていたが、記録を当たると**第78手への評**だった。名言は、しばしば別の場面に引っ越す
3. **数字の食い違いを放置しない**：李世乭のタイトル数は「14冠」と「18冠」の両方が流通している。本文では冠数を断定せず「世界タイトルを数多く手にしてきた」と表現した。数字を書くときは、数え方までセットで確認する
4. **推定と事実を分ける**：「1万分の1」は、AlphaGo の方策ネットワークによる「人間がその手を打つ確率」の推定値だ。事実として起きたのは「その手が打たれ、勝敗を動かした」ことまで。推定値は、誰の推定かを明示して使う
5. **本人の言葉は、要約と引用を分ける**：李世乭の発言は、対局後の驚きや第5局の黒番希望、引退時の言葉など、いずれも趣旨の要約として書いた。一字一句の引用にするには原文の確認が要る

AIの「すごい逸話」は、これからも増えていく。感動する前に、30分だけこの手順を通す。それだけで、伝説と事実の境目はずいぶんはっきりする。
