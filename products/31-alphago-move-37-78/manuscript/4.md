# 『「1万分の1」の手は、2つあった』有料パート　2つの手を確かめる ― 棋譜と検証台帳

（ドラフト。2026-10-24 作成。無料部（0.md〜3.md）の要約ではなく、棋譜そのものを読むための実用パートとして設計。価格は ¥500 に決定（2026-10-25））

無料記事では物語として追ってきた2つの手を、ここでは「棋譜」という記録の側から読み直します。囲碁のルールを詳しく知らなくても、着手の座標と勝率の動きを追うだけで、なぜこの2手が特別だったのかを自分の目で確かめられるようになります。

あわせて後半では、この記事自体が伝説的な逸話をどう検証してきたか——「神の一手」といった語られ方を鵜呑みにしないためのチェックリスト——を公開します。AI時代の「すごい話」全般に応用できる手順です。

## 1. 棋譜の座標の読み方

囲碁の棋譜は、19×19の盤面を座標で記録します。

- 横軸はアルファベットの A から T（ただし I は数字の1と混同しやすいため飛ばす）
- 縦軸は数字の 1 から 19
- たとえば「P10」は、左から15列目・下から10行目の交点です（I を飛ばす約束のため、P は15列目になります）

この約束さえ分かれば、世界中の棋譜データベースで、あらゆる名局を同じ形で再現できます。

## 2. 第37手＝黒の P10

第2局、AlphaGo（黒）の37手目は、座標でいうと **P10** でした。AlphaGo にとって19番目の石です。

局面を大まかに言うと、右辺で白の石が寄ってきている場所に、黒が五路の位置から「肩」を衝いた形です。

- 古典的なセオリーでは、序盤の五路は「地に結び付きにくく、効率が悪い」とされる
- だからこそ、プロの解説者の第一感は「ミスではないか」だった
- ところが AlphaGo は「点差」ではなく「勝率」を最大化する設計のため、人間の感覚では「緩く見える手」でも、勝率が最も高いなら選ぶ

実際この第2局では、終盤の167手目にも「明らかなミスに見える手」が現れ、解説者を困惑させました。アン・ヨンギル（安永吉）八段はこれを「勝利宣言のようなものかもしれない」と評したと伝えられています。点差を広げるのではなく、負ける可能性を消していく——第37手の「理解しにくさ」の正体は、この設計思想の違いにあります。

## 3. 第78手＝白の L11

第4局、李世乭（白）の78手目は、座標でいうと **L11** でした。盤のほぼ中央です。

この手は「ワリコミ」——黒石と黒石の間に白石を割り込ませ、黒の連結を脅かしながら自軍の連絡を図る手筋でした。手筋そのものは基本形ですが、問題は「この局面で、それが成立するかどうかは、膨大な変化を読まなければ分からない」という点にあります。

AlphaGo の反応を、勝率の数字で追うとこうなります。

| 時点 | AlphaGo の自己評価 |
| --- | --- |
| 79手目（第78手を受けた直後） | 勝率 約70%（評価値はまだ AlphaGo 優位） |
| 87手目 | 評価が急落し始める |
| 87〜101手 | 普段は見られない悪手が連続 |
| 92手目まで | 李が形勢を逆転 |
| 180手目 | AlphaGo が投了 |

ポイントは、78手の直後には、AlphaGo の評価値に異変がまだ表れていなかった、という点です。解説者のデイビッド・オルメロドは、探索の過程で「起きにくい変化筋」が枝刈りされ、その先にあった重要な変化が探索のレーダーの外に置かれた、と分析しています。DeepMind 自身も後に、自分たちにも分からない弱点が AlphaGo にあり、李がそれを突いた、という趣旨を述べています。第78手は、その弱点が盤上に現れた一手だったと言えます。

## 4. 伝説を検証するチェックリスト

第37手と第78手の物語は、10年の間に何度も語り直され、その過程で少しずつ「盛られて」きました。この記事の執筆で実際に起きた例とともに、検証の手順を示します。

1. **一次の記録に当たる**：棋譜・対局データ・本人の発言記録など、元の記録を確認する（今回は、棋譜は対局データに当たり、DeepMind の公式解説と2016年当時の報道を土台に、Wikipedia の対局ページを補助として使いました。Nature 論文は、AlphaGo の仕組みの説明の根拠に限って参照しています）
2. **「誰が言ったか」を確かめる**：「神の一手」と評した古力九段の発言は、当初あちこちで第37手への評として紹介されていましたが、記録を当たると**第78手への評**でした。名言は、しばしば別の場面に引っ越します
3. **数字の食い違いを放置しない**：李世乭のタイトル数は「14冠」と「18冠」の両方が流通しています。本文では DeepMind と Wikipedia の表記に合わせて「国際タイトル18冠」とし、「14冠」は主要世界戦のみの数え方と思われますが、確定はできていません。数字を書くときは、数え方までセットで確認します
4. **推定と事実を分ける**：「1万分の1」は、AlphaGo の方策ネットワークによる「人間がその手を打つ確率」の推定値です。事実として起きたのは「その手が打たれ、勝敗を動かした」ことまで。推定値は、誰の推定かを明示して使います
5. **本人の言葉は、要約と引用を分ける**：李世乭の「創造的だ」という趣旨の発言は対局後会見で広く報じられていますが、一字一句の引用には原文の確認が要ります。この記事では、確認が済むまでは要約に留めました

AIの「すごい逸話」は、これからも増えていきます。感動する前に、30分だけこの手順を通す。それだけで、伝説と事実の境目はずいぶんはっきりします。
