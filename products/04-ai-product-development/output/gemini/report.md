7つのAIによる商品開発チームの3番目の担当として、市場調査・競合調査・無料代替の検証結果を整理したレポートを提出します。
ChatGPTによる全体方針およびClaudeによる批判的レビューを踏まえ、実際の市場データ（無料代替の存在、有料競合の価格帯、AI代替リスク）を検証しました。
# 1. ChatGPT案の市場面からの評価
ChatGPTが提示した3つの候補について、市場調査の観点から評価します。
 * **候補1（AI業務改善スターターキット / 汎用プロンプト集）: 【評価：低】**
   2026年現在の市場において、汎用的な「メール作成」「議事録要約」プロンプトは、無料ブログ・SNS・YouTube・無料noteで無数に配布されています。また、Microsoft CopilotやGoogle WorkspaceへのAI組み込みが進んだため、「プロンプト単体」でお金を払う層はほぼ存在しません。
 * **候補2（特定業務向けExcel/スプレッドシート＋AIテンプレート）: 【評価：中〜高】**
   「業務を最後まで完了させる道具」としての需要は堅調です。ただし、「ただのExcel枠組み」は無料配布サイトに溢れているため、「手入力の手間をAIで9割削減する具体的なデータ処理フロー」が組み込まれていることが必須条件となります。
 * **候補3（AI商品企画・検証キット）: 【評価：低〜中】**
   副業志望者の関心は高いものの、購入ターゲット（副業未経験者）は購入心理ハードルが高く、離脱率も高い市場です。また、「AIにアイデアを出させる」行為自体が無料AI（ClaudeやChatGPT無料版）で完結しやすいため、無料代替リスクが極めて高いです。
# 2. Claudeの批判に対する回答
Claudeが行った批判的レビューに対し、市場データと照合した回答は以下の通りです。
 1. **候補1の自己矛盾（No-Go判定）について:** **完全に同意**します。市場にも無料のプロンプト集が溢れており、単体のプロンプト集として有料化することは極めて困難です。
 2. **候補2の無料Excelテンプレート問題について:** **完全に同意**します。BizoceanやMicrosoft公式、Notion公式等で質の高い無料テンプレートが多用されています。有料化の鍵は「テンプレートの見た目」ではなく、**「ぐちゃぐちゃの生データを、AIプロンプトと関数で一瞬で整形・転記する仕組み」**にあります。
 3. **候補3の無料代替問題について:** **完全に同意**します。ChatGPTやClaudeに「この商品アイデアを批判して」と入力すれば無料でできてしまうため、商品単体としての価値構築は難しくなっています。
 4. **「note読者」と「購入者」の乖離について:** **極めて重要な指摘**です。読者は「AI開発のドキュメンタリー（読み物）」を求めており、商品購入者は「自身の作業時間を減らすツール（実用性）」を求めています。
 5. **AIリテラシーが高い層による「自力作成（無料代替）」リスクについて:** 想定読者は「プロンプトの試行錯誤（プロンプトエンジニアリング）に3時間かけるくらいなら、完成されたプロンプトとシートのセットを1,000円で買って3分で終わらせたい」という**「時間の節約」にお金を払う**と定義する必要があります。
# 3. 無料代替の調査結果
競合・無料ツールの調査結果は以下の通りです。
 * **無料テンプレートの蔓延:**
   * **Notion:** 公式マーケットプレイスやビジネス系メディア（Alternative Work等）にて、顧客管理（CRM）、案件管理、タスク管理の高品質テンプレートが**完全無料**で配布されています。
   * **Excel/Googleスプレッドシート:** 予実管理、見積書、タスク管理シートは大手サイトで無料ダウンロード可能です。
 * **無料AIツールの進化:**
   * 長文整理・自然な日本語整形は**Claude**無料版、最新リサーチは**Perplexity**や**Gemini**、Office連携は**Microsoft Copilot**で無料実行可能です。
 * **結論:**
   **「枠組み（シート）」や「単発の指示文（プロンプト）」は100%無料で代替可能**です。「手入力・整形・コピペという泥臭い作業」をゼロにする**統合パッケージ**でなければ有料価値は発生しません。
# 4. 有料競合の調査結果
デジタル商品販売サイト（BOOTH、Etsy、ココナラ、noteなど）の実売価格帯および状況です。
 * **無料〜500円帯:** 単一のNotionテンプレート、シンプルなExcel管理表、個人のプロンプト集（BOOTH、Etsyなど）。
 * **1,000円〜2,500円帯:** 案件・請求・確定申告を連動させた個人事業主向け統合Notionテンプレート（BOOTHで1,480円前後）、または解説動画・運用マニュアル付き高度スプレッドシート。
 * **5,000円以上:** ココナラ等での個別オーダーメイド制作（1時間程度の作業で1,000円〜、週次フォーマット作成で5,000円〜16,000円程度）。
 * **販売実績の留意点:** プラットフォーム上の多くの中小デジタル商品は「出品数は多いが、継続的に売れている商品はごく一部」です。評価数が数十件以上ついているものは、特定職種の「実務に直結するテンプレート」に集中しています。
# 5. 顧客の切実な課題候補
市場調査から見えた「お金を払ってでも解決したい切実な業務課題」の候補です。
 1. **【バラバラな連絡の構造化】**
   メール、LINE、チャットで届く顧客からの要望や見積依頼を、手作業で管理表にコピペ・整理する時間がもったいない。
 2. **【商談メモ・音声の即時データベース化】**
   商談後の乱雑なメモや音声文字起こしテキストから、「次回アクション」「決定事項」「顧客課題」を抽出してCRMに転記するのが面倒で放置してしまう。
 3. **【週次・月次の実績レポート作成】**
   毎週の業務日報や売上データを、上紙（サマリー）用にグラフ・コメント付きで整形する作業に毎週1〜2時間奪われている。
# 6. 最も有望な具体的業務
最も有望なターゲット業務は、**「乱雑なテキスト（商談メモ・メール・音声文字起こし）から、案件管理シート＆見積ドラフトへの即時自動変換業務」**です。
 * **理由:** 個人事業主や営業担当者は、「商談」そのものよりも「商談後のデータ入力・整理・見積作成」という後処理に激しいストレスを感じています。ここを数分で終わらせる仕組みには明確な対価（1,000円〜2,000円）が発生しやすいと考えられます。
# 7. 商品候補の評価
### 候補A: 「【非構造化データ→即入力】商談メモ・音声文字起こしを1分で案件管理・見積ドラフトに自動変換する標準化キット」
 * **ターゲット:** フリーランス、個人事業主、中小企業の営業・クライアントワーク担当者。
 * **解決する課題:** 商談後のメモ整理、タスク抽出、CRM入力、見積下書き作成に毎回30〜60分かかっている手間。
 * **対価を支払う理由:** 手動コピペが不要になり、入力漏れや見積遅れによる機会損失を防げるため。
 * **無料代替:** 無料のNotionテンプレートや単発プロンプトで試すことは可能だが、入力・出力のフォーマット定義やプロンプトチェーンの構築に数時間の試行錯誤が必要。
 * **競合:** BOOTHやEtsyのテンプレート（500〜1,500円）、ココナラのフォーマット作成（5,000円〜）。
 * **差別化:** 単なるシート配布ではなく、「コピペするだけの最適化プロンプト」＋「入力用Excel/スプレッドシート」＋「入力・出力の実例・失敗例マニュアル」のセット販売。
 * **想定価格:** 1,280円〜1,980円。
 * **制作難易度:** 中（AIチームでプロンプト検証とスプレッドシート設計が可能）。
 * **継続販売可能性:** 汎用性が高く、業務自動化の定番としてストック型販売が可能。
 * **ChatGPTによる無料代替可能性:** **【中】** 「このメモを要約して」レベルなら無料で可能。しかし、「特定のシート列に完璧に収まる形式でJSON/CSV化し、見積計算式に組み込むプロンプト」を作るには試行錯誤が必要なため、差別化可能。
### 候補B: 「【月次・週次報告が1分で完了】業務日報・プロジェクトログ自動集計＆役員報告文作成キット」
 * **ターゲット:** 複数プロジェクトを抱えるチームリーダー、会社員マネージャー。
 * **解決する課題:** 週末や月末にチーム全員の日報や進捗ログを読み込み、報告書用にフォーマットを整えて要約文を書く苦痛。
 * **対価を支払う理由:** 毎週金曜夕方の残業時間を直ちに30分〜1時間削減できるため。
 * **無料代替:** 無料Excel関数やChatGPTでの手動要約。
 * **競合:** 各種レポート作成ツール、ココナラの集計代行。
 * **差別化:** 業務日報用スプレッドシートと、コピペ一発で上司向け・役員向け報告文を作るAIプロンプトの完全連動。
 * **想定価格:** 980円〜1,480円。
 * **制作難易度:** 低〜中。
 * **継続販売可能性:** 中。
 * **ChatGPTによる無料代替可能性:** **【高】** 単発の報告文作成なら無料AIで容易に代替されやすい。
# 8. Go / Maybe / No-Go の判定
 * **No-Go（不採用）:**
   * **「汎用プロンプト集（ChatGPT候補1）」:** 無料代替が強すぎ、商品価値ゼロ。
   * **「AI商品企画キット単体（ChatGPT候補3）」:** 購入者の成果までの距離が遠く、無料AIで代用可能。
 * **Maybe（保留）:**
   * **「業務日報・報告自動化キット（候補B）」:** ニーズはあるが、社内環境（IT制約）によって使い勝手が大きく左右されるリスクあり。
 * **Go（採用推奨）:**
   * **「乱雑データ（商談メモ・音声）→案件管理・見積ドラフト自動変換キット（候補A）」:** 課題が極めて切実で、無料ツールとの差別化ポイント（プロンプトとシートの密接な連動構造）が明確。
