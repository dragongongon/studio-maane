# P35：『3人の会社は、なぜ4,400万ドルで売れたのか』（仮）

2012年12月、タホ湖のカジノホテルの一室で、社員3人・製品なし・売上なしの会社 DNNresearch がメール入札のオークションにかけられた。売り手は「座ることができない」大学教授ジェフリー・ヒントン（オークションの週に65歳の誕生日を迎えた）と、その大学院生2人。買い手は Google、Microsoft、Baidu、そして無名のロンドンのスタートアップ DeepMind。価格は4,400万ドルまで競り上がり、しかしヒントンは最高値の手前で自らオークションを止めた。AIの冬を生き延びた研究が「資産」として値付けされるまでの設計と、その判断を描く note 企画。P30〜P34に続く「歴史的転換点」シリーズの一編。

**現在地：初版を作成し、GitHub へ反映した（2026-10-26）。同日、AI レビュー round 完了（Discussion #86）→統合・ブラッシュアップ済み（research/synthesis-2026-10-26.md）。タイトル・価格は未決定（オーナーの承認事項）。noteへの公開・販売は未実施。**
