# P30 公開後の検証計画（承認前・2026-10-22）

## 目的

このシリーズの目的は、記事を公開すること自体ではなく、次の二つを検証すること。

1. 「AI技術の歴史を、研究者・企業・社会への広がりまでつないで説明する」内容に読者需要があるか。
2. 読者が次に何へ価値を感じるかを見極め、継続的な収益につながる商品候補を絞れるか。

単発の500円記事が1本売れるだけでは、月1万円の継続収益目標には直結しない。P30は当面、読者需要を知るためのコンテンツ資産として扱い、売上見込みを過大評価しない。

## 推奨する公開順（未承認）

1. 第1部「論文の向こう側にあった未来」：無料
2. 第2部「研究の世界から、日常の道具へ」：無料
3. 第3部「研究成果を、対話の形で届ける」：無料
4. 第4部「同じ論文から、分かれていく道」：無料
5. 第5部「ChatGPTだけではない。AIが薬の設計に挑む時代」：現時点では無料を推奨。読者反応と商品価値を確認するまで有料化を保留。

各記事の公開間隔は、読者が前の記事を読み終え、次の記事へ移る時間を確保できる範囲で設定する。投稿時刻は「朝が必ず有利」などと決めつけず、既存アカウントの実績があればそれを優先する。実績がなければ、無理なく継続できる時間を選び、時間帯の効果は少ない投稿数で断定しない。

## 公開前の必須チェック

- [ ] 各記事をnoteの編集画面に貼り付け、見出し・改行・引用・リンクを確認
- [ ] iPhoneの縦画面で第1〜5部をプレビューし、段落が長すぎないか、タイトルが切れないか確認
- [ ] 参考リンクを少なくとも公開用端末のブラウザで確認
- [ ] 記事末尾に、次の記事の公開後URLを正しく設定（公開前に架空のURLを入れない）
- [ ] サムネイルを作成し、縮小表示でもタイトルが読めることを確認
- [ ] タグを記事内容に合わせて選び、同義語を過剰に並べない
- [ ] 第5部を無料にするか有料にするか、販売説明文とともにオーナーが決定
- [ ] 公開・販売についてオーナーの明示承認を得る

## 記録する指標

公開から各記事について、同じ観測時点（例：公開後7日）で記録する。数字が少ない初期は、率だけで結論を出さず、実数も併記する。

| 指標 | 記録方法 | 分かること／注意点 |
|---|---|---|
| PV | noteの表示値 | 読まれた規模。インプレッションとは区別する |
| スキ数 | noteの表示値 | 反応の数。購入意向と同じではない |
| スキ率 | スキ数 ÷ PV | 小さい母数では変動が大きい |
| コメント | 数と内容 | 具体的な疑問・次に知りたいことを記録 |
| フォロー増 | 公開前後の差 | アカウントへの継続関心の手がかり |
| 次記事への遷移 | 計測できる場合のみ | 連載のつながりを評価。計測できなければ推測で埋めない |
| 有料記事の購入 | 実際の販売後のみ | 購入実績。閲覧数やスキから推定しない |

## 判断ルール

- PVが少ない場合：内容の良し悪しを即断せず、表示される機会・タイトル・タグ・サムネイル・投稿間隔を分けて検討する。
- PVはあるが反応が弱い場合：導入、記事の具体性、読者が得られる発見が伝わっているかを確認する。
- スキやコメントはあるが購入がない場合：関心はあるが有料化の理由が弱い可能性を考える。購入意向を直接確認できる機会がなければ、売れると断定しない。
- 反応が強いテーマが見えた場合：そのテーマについて、読者が実際に困っている課題や、繰り返し使える実用価値を調べてから有料商品化を検討する。

## 継続収益への接続

月1万円の継続収益を目指すなら、単発記事の販売だけでなく、繰り返し必要になる課題に対する商品・サービスを探す必要がある。P30で反応が得られた場合でも、すぐに月額商品を作らず、まず読者が何を継続的に必要としているのかを確かめる。

考えられる候補（未検証）：
- AIニュースを自分で評価するためのテンプレート／実践ガイド
- 論文や企業発表を、一般読者向けに読み解く定期的な解説
- AI技術の変化を業務・学習へつなぐ実用教材

これらは商品案であり、需要確認前に制作を拡大しない。

## 承認境界

本計画は内部用。noteへの投稿、公開、価格設定、販売は実施していない。オーナーの明示承認が必要。
