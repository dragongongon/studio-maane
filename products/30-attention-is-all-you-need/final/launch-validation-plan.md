# P30 公開後の検証計画（第5部＋特別編セット案反映・2026-10-22）

## 目的

このシリーズでは、記事公開そのものではなく、次の点を検証する。

1. AI技術の歴史を、研究者・企業・社会への広がりまでつないで説明する内容に読者需要があるか。
2. 読み物と実践教材を組み合わせた商品に、実際の購入需要があるか。
3. 読者が継続的に必要とする課題を見つけ、将来の収益につなげられるか。

単発商品が1本売れるだけでは、月1万円の継続収益目標に直結しない。売上見込みを過大評価せず、読者の実際の反応を記録する。

## 提案する商品構成（公開・販売は未承認）

### 無料連載
1. 第1部「論文の向こう側にあった未来」
2. 第2部「研究の世界から、日常の道具へ」
3. 第3部「研究成果を、対話の形で届ける」
4. 第4部「同じ論文から、分かれていく道」

### 有料候補
- 第5部「ChatGPTだけではない。AIが薬の設計に挑む時代」
- 特別編「AI論文を自分で読み解くための実践ガイド」（仮題）

第5部と特別編は別記事として維持し、同じ有料マガジンに収録する案を推奨する。第5部は読み物として楽しめる価値を担い、特別編はワークシート・図表ガイド・用語集・記入例・実践演習を提供する。特別編だけでは難しそうという懸念に対応する商品仮説だが、需要はまだ未検証。

## 推奨する検証順序

1. 第1〜4部を無料記事として公開するか、オーナーが判断する。
2. 公開する場合は、同じ観測期間でPV・スキ・コメント・フォロー増を記録する。
3. 作成済みの無料サンプル原稿（`final/free-sample-ready-to-paste.md`）を、内部レビュー後に公開可能な形として整える。公開前に、初見の読者が使い方を理解できるか確認する。
4. 読者が第5部と特別編のセットに何を期待するか、購入をためらう理由は何かを確認する。
5. 商品説明と内容を改善し、価格案を比較する。
6. オーナーが明示承認した場合に限り、有料マガジンの作成・価格設定・販売を行う。

noteの有料マガジンは複数記事をまとめて販売するための機能として案に適している。実際の設定時には、公式ヘルプで最新の条件・価格範囲・操作手順を確認する。機能があることと、この商品が売れることは別問題である。

## 記録する指標

各記事について同じ観測時点（例：公開後7日）で記録する。初期は母数が小さいため、率だけで結論を出さず、実数も併記する。

| 指標 | 記録方法 | 注意点 |
|---|---|---|
| PV | noteの表示値 | インプレッションと区別する |
| スキ数・スキ率 | 表示値、スキ数÷PV | 小さい母数では変動が大きい |
| コメント | 数と具体的内容 | 読者が知りたいこと・疑問を記録 |
| フォロー増 | 公開前後の差 | アカウントへの継続関心の手がかり |
| サンプル反応 | コメント・回答など、取得できた範囲 | 取得できない数字を推測で埋めない |
| 購入数 | 実際に販売した後のみ | PVやスキから購入を推定しない |
| 購入後の利用感 | 得られた感想のみ | 感想が少ない場合は一般化しない |

## 判断ルール

- PVが少ない：内容の良し悪しを即断せず、表示機会、タイトル、タグ、サムネイル、投稿間隔を分けて検討する。
- PVはあるが反応が弱い：導入、具体性、読者が得られる発見が伝わっているか確認する。
- 第5部への反応はあるがセットへの関心が弱い：読み物としての関心と教材への支払意思は別と考える。
- サンプルを見ても使い方が分からない：販売訴求を強めるのではなく、教材の導線と記入例を改善する。
- 購入意向はあるが購入がない：意向を実際の購入と混同せず、価格、購入障壁、商品説明を調べる。
- 初期の購入があっても、継続収益が成立したとは判断しない。継続的な需要と運営負荷を別途検証する。

## 月1万円の継続収益への接続

P30の売上だけで目標達成と見なさない。反応があれば、読者が継続的に困っている課題を確認してから次の商品候補を考える。

候補（未検証）：
- AIニュースを根拠に基づいて評価するテンプレート／実践ガイド
- 論文や企業発表を一般読者向けに読み解く定期的な解説
- AI技術の変化を業務・学習へつなぐ実用教材

需要を確認する前に制作を拡大しない。

## 承認境界

本計画は内部用。noteへの投稿、公開、有料マガジン作成、価格設定、販売は実施していない。オーナーの明示承認が必要。
