# note記事・有料マガジンへのリンク設定ガイド（内部用）

更新日：2026-10-22  
状態：手順確認済み／note上の設定は未実施

## 1. 記事本文から別の記事へリンクする

### iPhoneのnoteアプリ
1. リンク先の記事を開き、記事下部の共有ボタン、またはブラウザのアドレスバーから記事URLを取得する。
2. リンクを付けたい記事を編集する。
3. 本文中でリンクにしたい文字列を選択する。
4. 編集ツールバーのチェーン（リンク）アイコンをタップする。見当たらない場合はツールバーを横にスクロールする。
5. コピーした記事URLを入力し、［OK］をタップする。
6. 下書き状態でリンク先が正しいか確認する。

### PCブラウザ
1. リンク先の記事のURLをアドレスバーからコピーする。
2. 編集画面でリンクにしたい文章を選択する。
3. ツールバーのチェーンアイコンを押し、URLを入力して［適用］する。
4. プレビューでリンク先を確認する。

### 推奨する表示テキスト
- 「第1話：論文の向こう側にあった未来を読む」
- 「前回の記事：研究の世界から、日常の道具へ」
- 「次の記事：研究成果を、対話の形で届ける」

単に「こちら」だけにせず、リンク先で何が読めるかを文章で示す。

## 2. 記事本文からマガジンへリンクする

1. 対象マガジンをnote上で作成した後、マガジンのページを開く。
2. マガジンページのURLをコピーする。
3. 記事編集画面で「第5話と論文読解特別編を収録した有料マガジンはこちら」など、リンクにしたい文言を選択する。
4. チェーンアイコンから、コピーしたマガジンURLを設定する。
5. プレビューで、リンクが正しいマガジンページを開くことを確認する。

**重要：** マガジンが未作成の間は、正規URLを取得できないためリンクを確定しない。URLを推測・捏造しない。

## 3. 記事末尾の導線案（内部草案）

第5話と特別編第5話では、Transformer論文の共著者の一人、ヤコブ・ウシュコレイト氏が共同創業したInceptive社によるAI創薬の取り組みも紹介します。論文に関わった研究者がその後どのようにAIの応用領域を広げているのかをたどりつつ、Transformer論文が直接、薬を生み出したという誤解を避け、前臨床データの限界も確認します。さらに、Transformerの原論文を自分で読み解くための図表ガイド、用語集、ワークシート、記入例、5分間の演習も用意しています。

**第5話と論文読解特別編を収録した有料マガジンはこちら**

上の太字部分に、作成後のマガジンURLをリンク設定する。実際の公開時には、記事の収録内容・試し読みの有無・価格を確定し、本文とマガジンの表示が一致していることを確認する。

## 4. 読者が購入前に内容を確認できるようにする

選択肢は2つ。

### A. 有料記事の「試し読みエリア」
- 有料マガジンに収録する記事の編集画面で、無料で読める範囲と有料部分の境界を設定する。
- 境界より上の内容は公開状態で読め、下の内容は購入者向けになる。
- 特別編の冒頭で「この教材でできること」「使い方」「収録内容」を説明し、その後に具体的な教材・演習へ進む構成が適する。
- 設定後、未購入者として見える範囲を確認する。

### B. 独立した無料サンプル記事
- 最小版ワークシート、短い記入例、1分練習を無料記事にする。
- サンプル記事末尾から、有料マガジンのページへリンクする。
- サンプルの価値を無料で体験できる一方、別記事の作成・管理が必要になる。

初期は、まず特別編の冒頭を試し読みエリアとして使えるか検討し、無料サンプル記事は追加の手間と需要検証上の利点を比較して決める。どちらも外部公開前にオーナー承認を得る。
