# AIニュース評価ワークシート（購入者向け付録・試作）

> 目的：AIに関する発表を読んだとき、「すごそう」という印象だけで判断せず、何が確認でき、何がまだ言えないかを5〜10分で整理する。
>
> このシートは投資・医療上の判断を行うためのものではない。ニュースの主張と証拠の距離を見極めるための読解補助である。

## 1. まず発表を一文にする

- **発表主体：**
- **発表日：**
- **何をしたと主張しているか（事実を一文で）：**
- **何が新しいとされているか：**

「AIが画期的な成果を出した」のような評価語ではなく、実際に行ったことを書く。

## 2. 証拠の強さを分ける

| 確認項目 | 記入欄 | 見るポイント |
|---|---|---|
| 証拠の種類 | □企業発表 □論文 □査読済み論文 □独立検証 □その他 | 発表主体の説明だけか、第三者が検証できるか |
| 実験・検証段階 |  | シミュレーション、実験室、動物、人間での試験、実運用のどこか |
| 比較対象 |  | 既存手法・標準治療・ベースラインと比べたのか |
| 規模 |  | サンプル数、実験回数、対象範囲は十分か |
| 指標 |  | 何を測り、どれだけ改善したのか。評価指標は目的に合っているか |
| 限界 |  | 著者・企業が明記した制約は何か |
| 次の関門 |  | 実用化までに何を追加で示す必要があるか |

## 3. 結論を3段階に分類する

### A. 確認できたこと
発表資料や研究で、実際に測定・実施されたと確認できる範囲に限定する。

### B. 有望だが、まだ仮説のこと
結果が示唆する可能性。妥当そうでも、追加検証が必要な内容はこちらに置く。

### C. 現時点では言えないこと
証拠が届いていない主張。たとえば、動物実験の結果だけから人間での有効性や安全性を断定しない。

## 4. 記入済みの例：AI設計mRNAを使ったCAR-T研究

**発表の要旨：** Inceptiveは、AIが設計したmRNA配列を用いた前臨床研究について発表した。

| 観点 | 評価例 |
|---|---|
| 証拠の種類 | 企業による研究成果の発表。発表元と独立した検証の有無は分けて確認する |
| 検証段階 | ヒト化マウスを用いた前臨床段階 |
| 比較対象 | 発表では既存の比較対象との結果が示されている |
| 規模 | 公表された図では各群 n=4。小規模な結果として扱う |
| 観察された結果 | 会社発表では、試験した5配列のうち3配列が比較対象を上回り、最良の配列で24時間時点のCAR発現が約3倍と報告された |
| まだ分からないこと | 人間で同じ結果が出るか、臨床上の有効性・安全性、再現性、承認までの見通し |
| 次の関門 | 独立した再現性、追加の前臨床データ、人間を対象とする臨床試験など |

**A. 確認できたこと：** 企業発表では、AI設計配列を用いたマウスでの前臨床結果が報告された。

**B. 有望だが、まだ仮説のこと：** AIによる配列設計が、特定の条件でCAR発現などを改善できる可能性がある。

**C. 現時点では言えないこと：** この結果だけで、患者に有効な治療法が完成した、あるいは人間で安全・有効だとは言えない。

> この例は企業発表の内容を整理したものであり、独立した医学的評価や治療推奨ではない。公開前に一次資料と数値を再確認する。

## 5. 読者自身の最終判定

- **ニュースの見出しは、証拠より強い言い方をしていないか：**
- **自分が確実だと思い込んでいたが、実は未確認だった点：**
- **判断を変えるために必要な追加証拠：**
- **現時点で妥当な一文要約：**

## 6. 使い方のルール

1. 見出しではなく、発表元の一次資料から始める。
2. 企業の主張と、独立に確認された事実を混同しない。
3. 比較対象・規模・検証段階が書かれていなければ、「不明」と記入する。
4. 「証拠が見つからない」を「効果がない」と読み替えない。
5. 結論は証拠の範囲内にとどめ、将来の可能性と現在の実証を分ける。
