# P30：必要なのは、Attentionだけだった

2017年の論文「Attention Is All You Need」と8人の著者、Transformer以後の技術発展、研究成果が社会に届く過程を扱うnote企画。AI初心者向けの無料記事候補4部と、論文読解を実践する有料記事候補で構成する。

**現在地：原稿・資料の整理とQA中。noteへの公開・販売は未実施。**  
0章の導入文は第1部冒頭へ統合済み。0.mdは管理用の草稿として残し、独立公開しない。無料記事は第1〜4部の4本。価格500円は候補にすぎず、確定していない。

## 最初に読むファイル

1. [STATUS.md](./STATUS.md)：現在の状態、未完了作業、次の一手。進捗確認の入口。
2. [CANON.md](./CANON.md)：企画の核、編集方針、事実関係の変更しない基準。
3. [manuscript/README.md](./manuscript/README.md)：原稿ファイルの一覧と、各稿の役割。
4. [final/qa-checklist.md](./final/qa-checklist.md)：公開前に満たすべき品質・承認条件。
