# 原稿ファイルの管理

## 原稿一覧
- `1.md`：第1部「論文の向こう側にあった未来」。既存原稿をベースとした作業稿。
- `2.md`：第2部「世界は、まだ気づいていなかった」。既存原稿をベースとした作業稿。
- `3.md`：第3部「発明した者と、世界に届けた者」。既存原稿をベースとした作業稿。
- `4.md`：第4部「八人は、同じ未来を選ばなかった」。既存原稿をベースとした作業稿。
- `特別編.md`：有料記事候補の統合作業稿。最終稿ではない。
- `論文読解ワークシート.md`：特別編に付ける実用テンプレート。
- `論文図表ガイド.md`：原論文の図表を読むための補助ガイド。

## 編集方針
第1部〜第4部は、既存チャットで提示された原稿をベースとする。ゼロから書き直さず、語り口と構成を維持しながら、事実確認・根拠の明示・読みやすさの改善を段階的に行う。

原文の内容を黙って変更しない。事実誤認や根拠不足を見つけた場合は、まずレビュー記録に記載し、修正理由を明確にする。

## QA記録
- `../research/manuscript-review-2026-10-19.md`：第1〜4部の初回レビュー、優先度別の修正候補、確認資料。

## 公開前に必ず行うこと
- 原稿中の事実主張を一次資料・信頼できる報道で確認する。
- 人物の現在の所属・肩書きは公開直前に確認する。
- 無料4部と特別編の重複を整理する。
- 参考資料をクリックできるURLにする。
- note公開・販売はオーナーの明示承認後に限る。
