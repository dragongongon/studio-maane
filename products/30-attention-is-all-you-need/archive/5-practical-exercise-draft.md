## 実践編：次のAIニュースにも使える評価ワークシート

ここまでの事例を、今回だけの知識で終わらせないために、別のAIニュースを読むときにも使える手順にしておこう。目的は、ニュースを無条件に信じることでも、疑って退けることでもない。**発表された事実と、そこから期待されることを分ける**ことだ。

### 1. まず、発表を一文にする

最初に「誰が、何を、どの段階で確かめたと発表したのか」を一文で書く。「AIが画期的な成果を出した」のような評価ではなく、実施したことを記す。

### 2. 次に、証拠を確認する

| 確認項目 | 自分への質問 |
|---|---|
| 発表主体 | 企業自身の発表か、論文か、独立した第三者の検証か |
| 検証段階 | シミュレーション、細胞、動物、人間での試験、実運用のどこか |
| 比較対象 | 何と比べて、どの指標が改善したのか |
| 規模 | サンプル数や実験回数は示されているか |
| 限界 | 何が未確認で、どの条件に結果が限られるか |
| 次の関門 | 次に何を確かめれば、主張を強められるのか |

情報が見つからなければ、無理に埋めず「不明」とする。情報がないことは、効果がないことの証明でもない。

### 3. Inceptiveの事例に当てはめる

| 項目 | 記入例 |
|---|---|
| 発表の要旨 | AIが設計したmRNA配列候補を用いたCAR-T関連の前臨床研究について、Inceptiveが結果を発表した |
| 証拠の種類 | 企業自身による発表。独立検証の有無は別に確認する |
| 検証段階 | ヒト化マウスを用いた前臨床段階 |
| 規模 | 公開された図では各群 n=4 |
| 報告された結果 | 会社発表では、試験した5配列のうち3配列が比較対象を上回り、最良の候補で24時間時点のCAR発現が約3倍と報告された |
| まだ分からないこと | 人間でも同じ結果になるか、臨床上の有効性・安全性、再現性、承認の見通し |
| 次に必要な証拠 | 追加実験や独立した再現性の確認、人間での有効性・安全性を評価する臨床試験など |

この記入例から導ける結論は、次のように三段階で表現できる。

- **確認できたこと：** 企業発表では、AI設計配列を用いた動物での前臨床結果が報告された。
- **有望だが、まだ仮説のこと：** 特定の条件では、AIによる配列設計がCAR発現などを改善する候補を見つけられる可能性がある。
- **現時点では言えないこと：** この結果だけで、人間での有効性・安全性や、承認される治療薬の完成を断定することはできない。

### 4. 読者自身で使う記入欄

別のAIニュースを読んだら、以下を埋めてみよう。

1. 発表主体と発表日：
2. 発表された内容を、評価語を使わず一文で：
3. 証拠の種類と検証段階：
4. 比較対象・規模・測定指標：
5. 発表資料が明らかにしていないこと：
6. 期待されているが、まだ実証されていないこと：
7. 次に必要な検証：
8. 現時点で妥当な一文要約：

最後に、見出しと自分の要約を比べる。「AIが薬を完成させた」と「AIが設計した候補の前臨床結果が報告された」では、主張の強さが違う。証拠が支える範囲を超えずに書くことが、AIニュースを読むときの基本になる。

このワークシートは医療・投資判断の代わりではなく、発表の主張と証拠の距離を整理するための読解補助だ。個々の数値や研究の解釈は、元の発表資料と研究内容を確認したうえで判断したい。
